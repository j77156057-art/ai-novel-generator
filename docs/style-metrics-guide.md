# 文风指标的正确用法与常见误用

> 起因：多轮优化把「句长 60.3」当逐段目标，做了大量无效工作。这里记录正确口径。

## 一、句长是分布，不是标量

参考语料（雪中悍刀行 990 章）的 60.3 字/句是**全书平均**。同一本书内部：

| 段落类型 | 平均句长 |
|---|---|
| 环境铺陈 / 心理描写 | 80-100+ |
| 常规叙事 | 40-60 |
| 对话密集段 | 20-30 |
| 紧张动作段 | 15-20（大量一句成段） |

**真实特征是「长短交错，随场景变化」，不是「每句都长」。**

实测抽样：全书短句占比最高的那个 chunk，句长只有 20.0，短句占 45%：

```
呸呸呸，这玩意能吃
甭废话，吃
地瓜
能生吃
能
真他娘的脆甜
```

这就是雪中自己的写法。**拿 60.3 要求每一段，等于要求作者不许写短句。**

### 正确的验收方式

不看单一段落的均值，看三件事：

1. **整章分布**：≤10 字、11-30 字、31-60 字、60+ 字各占多少
2. **长短是否交错**：一段之内既有短句也有长句
3. **短句是否有内容**：见下一节

## 二、碎句不等于 AI 腔

句长低有两种完全不同的成因，必须区分：

| 成因 | 特征 | 处理 |
|---|---|---|
| **有效节奏** | 短句承载具体动作/物件/对白，推进情节 | 不动 |
| **AI 腔** | 短句是情绪、状态、空泛感受 | 要治 |

判据用「空话词 vs 具体指称」的比值：

**空话词**（有这些 = 危险）：心中、心里、情绪、感受、仿佛、似乎、一丝、一抹、
涌起、泛起、复杂、莫名、不由得、不禁、眼中闪过、嘴角、眼神

**具体指称**（有这些 = 有效）：刀、剑、船、水、火、墙、门、石、木、泥、血、
手、脚、肩、背，以及走、跑、蹲、抓、握、拔、按、喊、问、看、望等动作

实测对比（生成段 vs 参考语料段）：

| 来源 | 句长 | 短句数 | 空话词 | 具体指称 | 判定 |
|---|---|---|---|---|---|
| 生成段 2 | 18.4 | 22 | 4 | 217 | 有效节奏 |
| 生成段 4 | 25.9 | 62 | 5 | 248 | 有效节奏 |
| 参考语料短句段 | 20.0 | 21 | 0 | 27 | 有效节奏 |

生成段 2 句长 18.4 与参考短句段的 20.0 几乎相同，信息密度反而是后者的 4.4 倍。
**这类碎句不该改。**

## 三、句号密度是更可靠的指标

平均句长会被「一句成段」的排版稀释，句号密度不会：

| 文本 | 句长 | 句号/千字 |
|---|---|---|
| 参考语料 | 60.3 | **10.9** |
| 生成（关闭改写） | 16.3 | **59.6** |
| 生成（开启改写） | 30.1 | **33.6** |
| 改写任务实测（M3） | 60.7 | **17.1** |

**句号密度 > 25/千字基本可以判定为 AI 腔式碎句**（每 40 字就一个句号）。
它比平均句长更能反映「有没有被句号切断」。

## 四、统计指标对模型的约束力约等于零

系统提示里写着「句长 60.3±20.8 字，每千字句号 10.9」，实测生成 16-23 字/句。
把这个统计指纹块整个删掉，句长反而从 23.0 升到 26.4。

**数字指令在长上下文里会被稀释甚至反向。** 有效的只有：

- 可读的原文样例（脱敏后）——承载「长句到底怎么断」
- 明确的、带后果的指令措辞（「必须写满 N 字，少于 N 字视为不合格」比「建议 N 字」有效 4 倍）

## 五、任务形态比模型能力更重要

同一模型（MiniMax-M3）、同一套风格要求：

| 任务形态 | 句长 | 耗时 |
|---|---|---|
| 一次性生成 3000 字新内容 | 16.3 | 4.7 min |
| 改写已有的 900 字 | 60.7 | 19s |

试过 6 个模型、13 种推理参数、5 组 prompt 结构（去叙事规则 / 去统计指纹 /
极简 system + 样例前置），结论一致：**prompt 越短、指令越直接，句长越高**。

所以追长句要改任务形态（拆成「生成粗稿 + 改写文风」两段），不是调 prompt。

## 六、反面案例：两个把我带偏的错误指标

### 1. 「少用句号」被理解成「不用标点」

提示词写「多用长句，少用句号」，模型输出 1036 字**零标点**，平均句长算出来 1036。
那不是长句，那是把整段连成一串。

正确说法：**「把句号改成逗号」**——动作明确，不会被理解成删除。

指标层面要加保护：句号密度 < 5/千字时，「平均句长」失去意义，应直接判失败。

### 2. 脱敏占位符不等长导致句长被推高

首版用 `【人名3】`（5 字）替换 2 字人名，脱敏文本从 13112 字涨到 16110 字（+23%），
句长被推高 23%。模型从样例里学到的句长因此是错的。

正确做法：**占位符与原词等长**（`＃1` 替换 2 字名、`＃1＃` 替换 3 字名）。
实测等长后字数变化 +0.8%、句长变化 +0.8%，句法保真。

## 七、结论：怎么验收文风

1. **不看单段均值**，看整章分布（≤10 / 11-30 / 31-60 / 60+）
2. **句号密度 ≤ 25/千字**（参考 10.9）
3. **短句要有内容**：短句里的具体指称数 > 空话词数
4. **对白引号保留**：改写前后的引号数不能明显下降
5. **人工读三段**：有没有 AI 腔、有没有情绪直陈、有没有段尾升华

**不要用「平均句长接近 60.3」当验收线。** 那不是这本书的特征，那是全书平均值，
且短句段本身就应该是 15-25。
