## 2. 327 个残留窗口的第二轮复核：6 种形态

按「消费清洗后仍会进提示词」的口径重新统计，327 个窗口归为 6 种形态：

| 形态 | 数量 | 判定 | 依据 |
|---|---:|---|---|
| `wap..info` / `..info` / `.info` | 259 | 删 | 站点域名尾巴，插在句中（`…王府的名刺。.info轩辕青锋站在…`） |
| `全文阅读`（外来书名 + 后缀） | 19 | 删 | 如 `洪荒传奇录全文阅读`、`无限大冒险全文阅读` —— 别的书名插在句中 |
| `小说5200`（外来书名 + 后缀） | 14 | 删 | 如 `影子传奇小说5200`、`封禁之神小说5200` |
| `一秒记住` / `壹秒記住` | 4 | 删 | 站点记忆口令整行 |
| `收藏` | 31 | **保留** | **正文里的正常动词**：「也都由她整理收藏在书箱中」 |
| `纵横` | 150 | **保留** | **绝大多数是正文**：「纵横术士司马灿」「李翰林纵横花场」；只有「纵横+月票/订阅」才是附注 |

另外三类**不删**（理由比上面更重要）：

- **`最新章节` ×36**：站点是**替换**了原字，不是插入
  （「网游三国重生最新章节花魁小娘子」← 原词被顶掉）。删掉会缺字，
  要修得从干净源重新入库。
- **`番外第N章` ×24**：作者的**章节结构标记**，删了会破坏章节划分。
- **`哭小说5200` ×1**（chunk 125）：站点 token 与正文一字重叠，删不得。

## 3. 怎么清的：两次返工才找到对的判据

清理规则设计走了三版，每版都被真实数据打回：

| 版本 | 判据 | 结果 |
|---|---|---|
| v1 | 「开括号 + 站点标记 → 删到行尾」 | **吃进正文**：`（..info好看的小说棉花糖与此同时，林符的黑狐栏子…` 被整段删，叙事没了 |
| v2 | 「广告词覆盖率 ≥ 80% 才删」 | 靠模糊词表，既漏真广告（`一秒记住【..info】，为您提供精彩小说阅读。` 覆盖率只有 0.667）又依赖单本书的词表 —— 正是「为单本书堆特例」 |
| v3 | **结构判据**：闭合括号块 / 纯 token / 以站点短语开头的整行 | 干净：26,014 字 / 1125 chunk，0 处正文损伤 |
| v4 | v3 + 贪心正则切书名 | **吃进正文**：`我不喜欢别人无限大冒险全文阅读骗我` → 删成「我骗我」 |
| v5 | v3 + **逐条审计的最小删除清单** | 定稿 |

**最终判据**（能写进产品的那种）：

- 只删**自带边界**的块：闭合括号块、纯 token、以站点短语开头的整行；
- 站点 token 里的**外来书名**长度不定（3~6 字），且与正文词形相近
  （`徐凤年恶魔法则` 是正文词、`影子传奇` 是外来书名），
  固定长度或贪婪匹配都会误伤 → 这类**逐条定最小删除范围**，不靠正则猜；
- 站点名跟随口号一起出现时（`（好看的小说棉花糖`），连站点名一起删，
  否则句子烂在中间。

### 4.1 语料手术（一次性，在副本上）

```text

```

### 4.2 机制改动（`app/ingestion/clean.py`，对**任何**语料生效）

把上面的「结构判据」搬进消费清洗模板，语料**在读的时候**就被清，
不用再靠一次性手术：

```text
CONSUMPTION_CLEAN_VERSION   4 → 5   （行为变了，归档绑定必须跟着变）
真实语料（5323 chunk）：
  改动 chunk                1117
  删除字符                  26,618
  删除片段                  1181
  消费清洗后残留窗口        2396 → 83
  已定位引文 1819 条        消费清洗后仍逐字成立 1819 条，失效 0
  删掉的最长片段            逐条看过，全是站点垃圾（最长的 82 字是一整条站点宣传语）
```

剩下的 83 个窗口 = **31 个「收藏」正文误报** + **19 个「全文阅读」+ 14 个「小说5200」**
（外来书名 + 站点后缀，插在句中，机制无法在不误伤正文的前提下自动切 ——
那 19+14 个由第 4.1 节的逐条清单清掉）+ **19 个嵌在词里的裸域名/未闭合括号**
（按既有策略保留为复核证据，见下）。

> **守住既有策略：裸域名只删「边界上」的**
> `tests/test_distill_residual_policy.py` 钉了一条契约：
> 「嵌在词里的裸域名（`甲.info乙`）与文学性用法**保留为复核证据**，不删」。
> 第一版机制改动把裸 token 一律删掉，**违反**了这条契约（全量回归里被抓到）。
> 改成：**只在句末标点/行首边界上、或被 `<strong>` 包着时**才删裸 token；
> 站点的真实注入点都在句读边界上，所以按边界收口既守住契约，
> 又几乎不损失效果（残留 64 → 83，差的那 19 个正是刻意保留的复核证据）。
> **不闭合**的括号形态（`（..info好看的小说`）同样保留为证据。

> **为什么「收藏」不能进删除模板**：`也都由她整理收藏在书箱中` —— 它是正文动词。
> 同一个「纵横」在正文里是「纵横术士」「纵横花场」，只有「纵横+月票」才是站点附注。
> 这类词只进 `_SUSPECT_RESIDUE`（**只标记不删**），在报告里留证据。
