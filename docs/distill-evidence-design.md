# 蒸馏证据修正

输入保留 v3 全部非空章。词项提示不是广告裁决，不按章排除。确定性明确模板只删精确区间，保留原坐标；未知交 Assistant 给 quote/start/end/category，校验坐标后仅保存提案，不自动改正文。未知数量不阻止完整实测。

L2 在调用前拒绝共享多个规范全名且无唯一归属的简称；独立姓名须由局部个人行为/说话证据支持。不得凭姓氏或专名黑名单判定。模型输出额外 claims，每条包含 field/value/quote/chapter/status(observed/inferred/unknown)/kind。引用必须存在于实际输入并匹配章号，只有 observed 且 value 为原文直接支持的保守摘录进入事实字段；其余在 evidence 审计中标待核。六字段旧档案仍可解析，渲染显式标记未核实；新蒸馏不把无证据旧格式当可靠。

验收：先 RED 覆盖歧义简称、未知/不存在引用、内心设想和字面/比喻区别、旧格式标记、收藏正文保留和未知不阻塞。生产入口调用同一规范化；升级 narrative_version 防复用旧产物。真实验证用副本 Distiller/Assistant，3 个经原文确认人名和完整规则后处理，然后完整 full 30%（979 中 293 章）低并发实跑，保留逐调用缓存和 checkpoint。引文存在与自动语义证明分开报告。
