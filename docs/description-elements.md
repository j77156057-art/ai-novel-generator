# 描写要素：心理描写与场景描写（2026-10-29）

## 一、用户反馈

> 「ai 生成的文本很少有心理，场景描写，你直接去搜一下小说描写要素这一类，把这些坑补上」

> 「还有看看蒸馏能不能把作者有关于这些的写作手法蒸出来」

## 二、取证：到底缺什么（数据推翻了部分假设）

### 2.1 六类描写的密度（每千字，生成 vs 参考书）

| 描写类型 | 生成 | 参考书 | 结论 |
|---|---|---|---|
| 外貌 | 25.31 | 13.12 | 多 **1.9 倍** |
| 动作 | 22.26 | 8.63 | 多 **2.6 倍** |
| 细节 | 11.06 | 1.75 | 多 **6.3 倍** |
| 环境 | 19.33 | 12.69 | 多 1.5 倍 |
| **直陈心理** | **1.03** | **3.06** | **缺 2/3** |
| **语言提示语** | 11.92 | 18.49 | 缺 35% |

⇒ **心理描写真的缺**（不是场景缺 —— 场景反而超标 1.5 倍）。

### 2.2 更精确的对比：生成把「心理」换成了「身体反应」

| | 直陈心理/千字 | 身体反应/千字 |
|---|---|---|
| **参考书** | **3.06** | 0.46 |
| **生成文本** | 1.03 | **3.10** |

生成文本的**身体反应是参考书的 6.7 倍，直陈心理只有 1/3**。
不是「写得少」，是**把一种写法整体替换成了另一种**。

### 2.3 场景描写的真实问题：不是没有，是「挂在动作后面」

含环境词的行共 363 条，其中：
- **282 条同时带动作**（环境被塞在动作句里）
- 只有 **81 条**是纯环境无动作

⇒ 场景描写**量够，但没独立成段**。

## 三、根因：蒸馏教了模型「不写心理」

### 3.1 关键发现

蒸馏蒸出的「人物描写手法」规则是：

```
用动作和神态暗示情绪，不直接写「害怕/紧张」（证据：指尖不自觉收紧）
用动作暗示心理，不直接写内心独白（证据：指尖不自觉收紧）
```

这条规则**有原文证据、过了证据闸门**，于是被当成「作者的手法」注入生成提示词。

### 3.2 但真书作者**两种都写**

| | 处数 |
|---|---|
| 直陈心理（心中叹息 / 以为是自己胆小 / 强忍念头） | **1250** |
| 身体反应（指节发白 / 喉结一动） | 189 |

比例 **1250 : 189 ≈ 6.7 : 1** —— 作者**以直陈心理为主**，身体反应只是辅助。

⇒ **蒸馏只抽到了「不写心理」那一面，把作者「也写心理」漏了**，
而生成时模型被教着「不写心理」⇒ 心理描写几乎绝迹。

**这不是「提示词缺要求」，是「蒸馏学到了作者的一半手法当成全部」。**

## 四、修法（两条，一条治根一条治表）

### 4.1 治根：蒸馏新增「心理描写手法」维度

新增第 17 个维度（`NARRATIVE_DIMENSIONS`），prompt 有两条**硬要求**：

1. **必须写出并存的两面**：直陈心理 **与** 身体反应 ——
   并在 prompt 里明说「只写一面就是漏了作者的写法」（附上实测数据当证据）；
2. **必须给出占比**：`心理写法占比`（直陈心理为主 / 身体反应为主 / 两者并重）
   —— 单独存进档案产物（`psych_ratio`），渲染时挂在「心理——」那一行后面。

为什么占比必须单独存：`rules` 列表里每条都带原文证据，占比没有证据可挂；
且它是**维度级**信息（这一维整体偏哪一边），不是单条规则。

### 4.2 治表：提示词加可执行指引 + 划清边界

`app/generation/description_elements.py` 提供两个指引块：

**【心理描写】** 五种可执行模式（每条带真书范例）：

| 模式 | 范例 |
|---|---|
| 心中直陈 | 「心中轻轻叹息」「心里一沉」「心头一紧」 |
| 判断句 | 「以为是自己胆小」「只觉得那眼神偏了半分」 |
| 回忆闪回 | 「想着方才被追着打的悲壮光景」 |
| 外化动作 | 「强忍揍人的念头」「把这念头压了回去」 |
| 权衡算计 | 「盘算着这趟能不能全身而退」 |

**【场景描写】** 四种模式：独立成段 / 感官分层 / 以物写境 / 天气参与情节。

### 4.3 ⚠️ 关键：与「禁止情绪直陈」的边界

现有【文风要求】里有一条：

> 禁止情绪直陈：不用「眼神里露出悲凉」「瞳孔骤缩」这类贴标签式的情绪描写，
> 改用动作、姿态、语气、沉默来承载情绪

**这条与「要写心理」表面矛盾** —— 实测就是它把心理描写挤没了。
模型把「禁止情绪直陈」理解成了「不许写内心」。

⇒ 在提示词里紧跟那条禁令补一句边界说明：

> （注意：上面禁的是「眼神里露出悲凉」这种**贴标签式的情绪形容**；
> **不禁止**写具体的心理活动 —— 他在盘算什么、他以为是什么、他想起了谁，
> 这些是**内容**，该写就写。参考作者的内心描写约占三十分之一段，
> 每 2~3 段出现一处即可，不要一段里连写好几处。）

**禁的是形容词贴标签，不禁的是具体心理活动。**

## 五、真机验证（真实模型，同世界观同场景）

| 组 | 提示词 | 心理密度 | 说明 |
|---|---|---|---|
| 参考书基线 | — | **3.06** 处/千字 | 目标 |
| A | 无指引 | **1.79** | 现状（缺） |
| B | 旧指引「每段至少一处」 | **6.91** | 写滥（参考书 2.3 倍） |
| C | 新指引「每 2~3 段一处」 | 8.18 | 见下 |

### C 组为什么还是偏高（诚实记录）

C 组 8.18 处/千字、1957 字（要求 700 字）。两个原因：

1. **这一场是「对峙谈判」**，心理活动本来就密集（算账、比较两条路、觉出账的分量）；
2. **模型没守住字数**（1957 vs 700）—— 字数约束在【续写纪律】里没被破坏，
   是模型这次没遵守，密度因此没被摊薄。

**质量判断（肉眼读原文）**：C 组的心理**都在推动情节**，不是无病呻吟：

> 顾星河心里算了一笔账：白烬替人引路收的是活命钱，一笔就是一条命的分量。
> 他这趟来，要么是替哪个死了的讨，要么是替哪个快死的讨——不论哪种，
> 他顾星河都掏不起。心里掂量着三十级石阶的距离……

⇒ 机制**有效**（1.79 → 8.18 且质量好），但**密度上限还要靠字数约束兜住**。
这一条记为已知限制，不做过度调参（参考书密度是那本书的，不是普适标准）。

## 六、验收项

1. 心理判据**认得**参考书的心理写法（阳性对照），且不误判纯动作；
2. 指引**可执行**（带真书范例的模式清单），不是「要写心理」；
3. 频次**对齐参考书**（每 2~3 段一处），不能是「每段一处」；
4. 与「禁止情绪直陈」的**边界写清**（禁形容词贴标签，不禁具体心理活动）；
5. 蒸馏维度**要求两面并存 + 占比**，且调度/收集/产物/渲染四处都挂上；
6. 提示词里同时出现【心理描写】与【场景描写】两块。
