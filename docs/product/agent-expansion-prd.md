# AI 小说 Agent 扩展最小增量 PRD

## 范围与基线

- 项目：`ai_novel_agent_expansion`
- 目标：在现有小说生成能力上增加隔离的助手 Agent，支持证据检索、分析诊断、经审批的修改和版本恢复。
- 基线 `b58c763` 已完成：角色锁定、节拍注入、KG 角色透传、premise system 提示。新能力不得削弱或绕过这些约束。
- LangChain、LangGraph、Deep Agents 仅为实现技术选项，不改变产品权限边界、审批要求或证据要求。

## 产品要求（P0）

1. **不同模型**：生成 Agent 与助手 Agent 必须使用分别配置的不同模型；提示词、会话上下文、工具权限及审计相互隔离。生成 Agent 负责生成正文，助手默认只读。
2. **检索与证据**：助手可检索小说，并在回答中提供章节、段落/片段定位及与存储原文完全一致的引用。无足够证据时明确说明，不得编造引用。
3. **角色与剧情分析**：助手分析角色出场、状态、关系、关键事件，以及主线/支线、时间线和伏笔状态；结论与推测分开，并附证据定位。参考语料与生成正文不得混淆。
4. **质量诊断**：至少诊断角色/状态/物品/时间一致性、剧情冲突、伏笔断裂、重复内容、AI 腔和结构漂移。问题须包含严重级别、定位、依据和建议；诊断不直接改稿。
5. **修改提案与审批**：助手可提出正文或提示词修改，提供目标版本、范围、修改前后差异、原因、证据及影响/风险。提案经用户批准后才应用；应用形成新版本。未批准、拒绝或过期提案不得改动正文、提示词或权威 Fact/KG。
6. **版本与回滚**：正文、提示词及批准的事实变更须保存为不可变版本，支持版本列表、差异比较和恢复为新版本。回滚保留历史并记录审计；操作失败不得产生半版本。提案目标版本变化后须标记过期。

## 验收标准

1. Writer 与 Assistant 调用不同模型；Writer 无法调用检索、提案应用或回滚，Assistant 无法调用正文生成或写入。越权请求被拒绝并审计。
2. 至少 20 条问答样例的章节、段落定位和引用均与原文匹配；无证据时返回明确无证据状态，不伪造内容。
3. 角色和剧情分析覆盖上述要求并能回溯到证据；参考语料与生成正文来源隔离。
4. 预置的一致性冲突、伏笔断裂、重复内容及 AI 腔样例均能生成可定位诊断，且诊断不直接修改正文。
5. 未批准/拒绝提案不改变内容；批准后创建新版本；版本变化使提案过期；应用失败无部分写入。
6. 验证 `v0 → v1 → v2 → 回滚为新版本 v3`：差异正确、历史可读、回滚后可继续生成。
7. 回归确认 `b58c763` 的角色锁定、节拍注入、KG 角色透传、premise system 提示均未退化。
