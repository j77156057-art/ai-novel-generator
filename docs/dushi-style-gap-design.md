# 都市臂风格出带：定位与改造（设计稿）

> 2026-11-02。起因：E1 人评收线（见 `ENGINEERING.md`「E1 收线」）⇒ 风格保真这件事
> **只能靠机器侧测** ⇒ 先把都市臂的出带定位清楚，再决定改哪里。

## 1. 为什么要重算，而不是直接照旧结论动手

仓库里已有的两条结论是：

- 「都市臂 **11 项里 8 项出带**（句长 0.56x、段均句数 3.48x、句号密度 2.32x、感叹号 0）」
- §10.6「21 项带内率 13~17」

这两条**用的都不是「参考书自己的分布」这把尺**：

| 量 | 旧记录里的带 | 都市书**自己**的带（整本拟合，unit_chars=3000） |
|---|---|---|
| 句长均值 | [17.76, 26.57] | **[32.49, 48.94]** |
| 句号密度 | [19.24, 31.96] | **[15.67, 22.86]** |
| 段均句数 | [1.25, 1.92] | **[1.04, 1.15]** |

产出段的句长约 21~25 字 ⇒ 在旧带里**在带内**，在**书自己的带里出带**。
⇒ 旧记录的那把尺对产出**更宽容**，带内率被系统性抬高。
⇒ 「都市臂出带」这件事**方向上是真的**（产出确实比这本书碎），
但**幅度被旧尺掩盖了** ⇒ 必须按书自己的分布重算，才知道该改多少。

## 2. 尺：先自证，再谈数

| 环节 | 口径 |
|---|---|
| 尺 | **参考书自己的分布**，p10~p90（`stylometry.band_check` 的同一把尺） |
| 粒度 | `unit_chars=3000`（与 `cut_units` 同粒度 ⇒ 档案带与实测可比） |
| 档案 | `build_reference_profile({书名: 正文}, unit_chars=3000)`（本地拟合，零模型） |
| 在带判定 | **自己按 `p10 ≤ value ≤ p90` 判** |

⚠️ **`band_check` 的返回里没有 `inside` 键** —— 只有 `value` / `band` / `bucket`
（`acceptance_lib` 里记过这个坑：按 `inside` 取值会得到**恒为 0 的假阴性**）。
⇒ 本轮我自己又踩了一次（第一次重算得到「中位 0/33 在带」，连书自己都过不了 ⇒
阳性对照立刻把它抓住）。**任何用这个 API 判带内的地方，都要自己算不等式。**

**阳性对照（尺自证）**：都市书自己的 10 个单元 vs 自己的档案 ⇒
在带项数中位 **30/33**（≈91%）⇒ 尺没问题。

## 4. 出带项分两类 ⇒ 杠杆在哪一层

**（甲）碎句类 —— 改写修得动**（`REWRITE_GATE_FEATURES = ("句长均值", "句号密度")` 这类）：

| 特征 | 出带段数 |
|---|---|
| 句长均值 | 13/13 |
| 句长p90 | 13/13 |
| 段均句数 | 13/13 |
| 句号密度 | 13/13 |
| 长句占比 | 12/13 |
| 句长CV | 7/13 |

**（乙）标点 / 词汇类 —— 改写碰不到**：

| 特征 | 出带段数 | 为什么改写碰不到 |
|---|---|---|
| 感叹号密度 | 13/13 | 改写只动断句，**不会凭空加情绪标点** |
| 四字格密度 | 13/13 | 词汇习惯层 |
| 逗号密度 | 13/13 | 断句会带一点，但主因是写法 |
| 逗号句内位置 / 引号内句号占比 | 13/13 | 标点位置习惯层 |
| 冒号密度 / 省略号密度 | 11~13/13 | 标点选择层 |
| 比喻密度 | 7/13 | 内容层 |

**几乎全在带内的那一项很说明问题**：`短句占比` 1/13 出带 ⇒ 产出**不是「碎片堆」**，
而是**句子整体偏短、且长度均匀**（书里有大量 35~49 字的长句，产出几乎没有）。
⇒ 改写（合并碎句）只能碰到（甲）这一半；
（乙）那一半**在写手与提示词层**，改写机制**结构上就够不着**。

## 5. 这一版不做什么

- 不改判据阈值（`MIN_*` 之类）—— 先定位，再谈改哪；
- 不动提示词的文体注入内容（那是另一轮）；
- 不重跑生成（先离线回放，**不烧额度**）；
- 不把「带内率」当唯一指标（它是二值口径，§9.4 已记过区分力弱）——
  结论以**配对差**（同一段产出 vs 参考书留出集）为主。

## 6. 待拍板（做完定位再定）

1. **（甲）碎句类**：改写已经修了一半（§10 把采纳率从 0/3 抬到 2/3），
   但 句长/段均句数/句号密度 三项**仍 13/13 出带** ⇒
   候选：把改写的目标带从「p10~p90」收紧到「p50 附近」/ 提高改写预算 /
   在**生成前**就要求写手写长句（提示词层）。
2. **（乙）标点/词汇类**：产出没有感叹号、没有四字格 ⇒
   候选：提示词里显式给出该书的**标点与词汇习惯**（从档案的 `spec` 里取，
   不是手写规则）/ 或在改写闸门里允许改写动标点（**扩改写的职责**）。
3. 旧结论怎么处置：§9.5 / §10.6 的数字要不要**标注为旧尺**并重算。

## 7. 验收口径

- 每个候选改造都必须报：**在带项数（33 项，中位）** + **配对差** + **阳性对照**（≥25/33）；
- 只报「带内率上升」不算通过 —— 阳性对照与带内数必须一起看；
- 改造后必须**再跑一次同样的离线回放**（同一份产出、同一把尺），否则不算数。
