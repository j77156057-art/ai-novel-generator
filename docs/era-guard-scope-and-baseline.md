# 时代检查的覆盖口径与结论前提

> 2026-11-15。本文是**口径文档**，不是实现说明；实现见 `app/kg/era_guard.py`、
> `app/kg/era_check.py`、`app/kg/data/world_profile.json`。
> 任何时候引用 `quality_json.era_check` 的命中数，都必须先读本文第一节。

## 1. 结论前提：现代基线放行 121 条，没违规 ≠ 没错

时代检查的词表共 **147 条**（原生 51 + 近现代 70 + 未来 21 + 未知 5，2026-11-15 实测）。

合规档位由项目基线决定（`_ALLOWED_BY_BASELINE`）：

| 基线 | 放行档位 | 真正有判定力的词 |
|---|---|---|
| 王朝 | 原生 | 近现代 70 + 未来 21（未知 5 不可判罚） |
| 近现代 / 现代 | 原生 + 近现代 | **仅未来 21 + 未知 5** |
| 未来 | 全部 | 无 |

所以对**都市/现代书**（如项目 6，`genre=都市` → 基线 `现代`）：
**147 条里 121 条恒放行**，命中数天然接近 0。这个 0 只能说明「未来词和未知词没出现」，
**证明不了正文没有时代穿帮**。未知 5 词（系统/机关/信号/镜子/琉璃）在代码上
也不可能 `hard_ban`：无通道标记 → `non_entity`，有通道 → 豁免或 `record_only`。

第 23–32 章实测（现代基线）：

- 词表词共出现 **343 次**，判为实体 112 次，**231 次（67%）未判**；
  其中 225 次是 `non_entity`（同一分句 −24/+16 窗口内没有动作/状态/存在/投射线索）。
  这是**结构性漏检**（「看了一眼手机」这类感知动词句全部不进判定），不是偶发。
- 同一批正文**强制按王朝基线**重扫：**10/10 章、110 条**
  （屏幕 52、手机 45、电话 9、电线 2、医院 1、玻璃 1）。
  词表本身有劲，只是对现代基线不设防。

**读表规则**：`era_check.violation_counts` 为空时，只能写「未发现未来/未知档越界」，
不能写「无时代错误」。

## 2. 逐类覆盖（2026-11-15 评估结论）

| 类别 | 能否覆盖 | 说明 |
|---|---|---|
| 新词（扫码/监控/外卖/算法/直播/二维码） | 不能 | 闭集精确子串匹配；10 章正文里扫码 3 次、监控/外卖/算法/摄像头各 1 次，全部不可见 |
| 外来概念（咖啡/沙发/逻辑/干部） | 不能，且不建议补 | 晚清已入汉语，无时代边界 |
| 器物 | 有条件能 | 须在词表内 + 档位不放行 + 分句窗口内有动作线索 + 过四道豁免闸 |
| 称谓 | 2026-11-15 起部分能（仅现代基线，仅官场称呼） | 见第 3 节 |
| 制度机构 | 2026-11-15 起部分能（仅现代基线） | 见第 3 节；王朝基线不装载 |
| 时间与纪年 | 2026-11-15 起部分能（仅现代基线） | 只收时辰/更次/年号这类词，无正则、无量词组合 |
| 货币与计量 | 2026-11-15 起部分能（仅现代基线） | 只收多字货币名；单字（两/贯/石/尺/斤/里）刻意不入表 |
| 交通与通讯 | 相对最好，仍单向 | 对王朝基线有效；对现代基线放行 |

结构性限制：不跨句/跨段；无分词、同义、错别字、繁简容错；无频率判据；
无「该出现而没出现」的反向判据；词表绑参考书（原生 51 条是打更人的物件，
对都市书无意义）。

## 3. 前现代档位（v18 新增，范围限死）

数据在 `world_profile.json.period_lexicon`，四类：制度机构、货币计量、纪年、
官场称呼。**刻意不碰宗门/修炼/仙侠题材词**（掌门、长老、弟子、灵石）——
那是题材设定，不是时代错误。

- **只对 `enabled_baselines` 声明的基线装载**，当前只有 `现代`。
  王朝/近现代书里这些词本来就合法，不装载即零影响。
- 装载时若与原生档重名（铜钱/银票），从原生家族摘出挂到前现代档：
  对现代基线才是错位，对王朝基线仍由原生档放行。
- 命中落 `needs_authorization`，`violation_notes` 里记 `period_mismatch`；
  有道具/剧组/博物馆这类正当语境时记 `exempt`（仍留痕）。
- 仍**只判不拦**：不改正文、不影响 `passed`、不进 `violations`、不触发重写。

## 4. 通道滥用聚合（v18 新增）

`channel_hit_no_introducer`（通道命中但同句缺引出人）仍逐条只记录；
新增聚合告警，写 `quality_json.era_check.channel_abuse`：

- 单章条数 ≥ `ERA_CHANNEL_ABUSE_THRESHOLD`（默认 3）→ `chapter_threshold`；
- 连续章数 ≥ `ERA_CHANNEL_ABUSE_STREAK`（默认 2）→ `consecutive_chapters`；
- 回看上限 `ERA_CHANNEL_ABUSE_LOOKBACK`（默认 8 条已落库留痕）。

阈值 <=0 关闭对应判定。它只回答「通道是不是被当成放行通道」，不判对错。

## 5. 不做的事（评估结论，留档）

- 称谓体系混杂（不加时代词典，用「同书两套体系并存」判）——等前三项回放数据再定。
- 纪年正则 / 计量组合——同上。
- OOV 候选池（正文高频词 − 档案词表）——只入池不判，往后放。
- 外来概念词表、语义借代、反向漏检——原理上做不到，不投入。
