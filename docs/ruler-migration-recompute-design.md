# 旧尺结论的统一重算（设计稿）

> 2026-11-02。起因：尺在 2026-11-01 换过（**特征 21 → 33 项、密度分母 全字符 → 纯汉字**），
> 换尺当天 §10.2 就写明「**换分母 = 档案分布作废，必须重拟合 + 重跑基线**」。
> ⇒ 仓库里有一批**分属两把尺**的数字。本设计稿要做的，就是把它们统一到当前尺，
> 并逐条标注旧结论的处置（可直接用 / 需重算 / 已作废）。

## 1. 为什么不能直接拿旧数字继续改

一个例子就够：`docs/dushi-style-gap-design.md` 里，
「都市臂 11 项里 8 项出带」与「§10.6 的 13~17/21」**量的是不同的东西** ——
旧记录用的带（句长 [17.76, 26.57]）**不是都市书自己的分布**（[32.49, 48.94]），
产出句长 21~25 字在旧带里算「在带内」，在书自己的带里算「出带」。
⇒ 不重算就不知道该改多少、改完有没有效。

## 2. 尺的口径（锁死）

| 项 | 取值 | 为什么 |
|---|---|---|
| 特征集 | 当前 `stylometry.FEATURES`（33 项） | 旧 21 项已换 |
| 档案 | **每本参考书各自拟合**（`build_reference_profile`） | 尺是「这本书自己的分布」，不是混合基线 |
| 粒度 | `unit_chars=1200` | 与产出一段的长度对齐（§9.2 锁的 `generation_length=1200`）⇒ 档案带与实测可比 |
| 在带判定 | **自己按 `p10 ≤ value ≤ p90` 算** | ⚠️ `band_check` 的返回**没有** `inside` 键（`acceptance_lib` 已记：按它取值 ⇒ 恒为 0 的假阴性） |
| 阳性对照 | 参考书自己的单元 vs 自己的档案，**中位 ≥ 25/33** | 尺不过自证 ⇒ 全部数字作废 |
| 连续量 | `style_distance` 的**分位**（主判据）+ 在带数（旁证） | §9.4 已记：在带是二值口径、区分力弱 |

## 4. 先把「每个臂用的是哪本书」钉死（不靠目录名猜）

产出里记着当时的**在带项集合**（旧尺 21 项）⇒ 拿它当指纹：
用候选书的档案重算在带集合，与记录集合算 **Jaccard**，最像的那本就是该臂的参考书。
§10 的跑次另有一手：记录里的 `band.detail` 带了 lo/hi ⇒ 直接与候选书的带比对。

## 5. 每条旧结论怎么重算

| 旧结论 | 重算方式 |
|---|---|
| §9.5 判决 1「自己那本排第几」 | 同一段产出对**六本书各自的档案**各算一次在带数 ⇒ 排名 |
| §9.5 判决 3「配对差」 | （自己那本命中数）−（其余五本命中数均值），逐段算再按书汇总，精确二项 + 精确置换 |
| §9.5 判决 3c「带宽校正后」 | 换成当前尺的带再算一遍 |
| §9.5 判决 4「引擎 vs 裸写」 | 同书配对：引擎臂命中数 − 裸写臂命中数 |
| §9.6 / §10.6「句号密度在带」 | 当前尺下逐段判 |
| §9.6 / §10.6「21 项带内率中位」 | 换成 **33 项**，并**同时报阳性对照** |
| §9.6 / §10.6「秒/段」 | 直接取产出里的 `seconds`（与尺无关，原样搬） |
| 「都市臂 11 项里 8 项出带」 | 换成 33 项 + 都市书自己的档案 ⇒ **12/33**（已在上一节做完） |

## 6. 输出

一张对照表（`docs/` 下，Markdown）：

| 对象 | 旧数字（旧尺） | 新数字（当前尺） | 差异来源 | 旧结论处置 |
|---|---|---|---|---|

「差异来源」必须能说清是**换尺**（21→33、密度分母）还是**换档案**（混合基线 → 书自己的分布），
不能只写「不一致」。

## 7. 本版不做什么

- 不改生产代码（判据阈值、提示词、改写逻辑一概不动）；
- 不重跑生成（**全部离线**，不烧额度）；
- 不因为数字变小就调阈值 —— 先把数统一，再谈改；
- 不删旧结论（保留在 `ENGINEERING.md` 与设计稿里，作为过程证据），只在其旁边标注状态。

## 8. 验收

1. 每个参考书的**阳性对照**中位 ≥ 25/33（不达标 ⇒ 该书的数字不作废也不采用，先查尺）；
2. 每个旧结论都有「旧数 / 新数 / 差异来源 / 处置」四栏，**不允许留空**；
3. 数字必须**可复算**：脚本与产出目录都写进文档，别人能重跑；
4. 涉及生产的结论（阈值、是否改判据）**另起一轮**，不在本设计稿范围内。
