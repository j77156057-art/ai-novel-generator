# 对白句长度：诊断与方案（2026-10-26）

> 状态：**诊断已做完，方案待审**。本文只写「现象—根因—候选方案—验收口径」，
> 实现要等方案被认可后再动。

## 一、现象

写手（MiniMax-M3.1-Flash，`reasoning_effort=low`）生成的对白，**句子被写得很短**。

同一口径对比（生成 = 本项目提示下两段共 11848 字；参考书 = 《北荒刀歌》中段 30 万字）：

| | 我们（原始模型输出） | 参考书 |
|---|---|---|
| 全部句 p50 | 9 字 | 26 字 |
| 叙述句 p50 | 9 字 | 25 字 |
| **对白句 p50** | **20 字** | **72 字** |
| 对白句 p90 | 34 字 | 191 字 |
| 纯台词段 / 含对白段 | 67% | 13% |
| 每段句数 | 2.23 | 1.90 |

⇒ **对白句比参考书短 3.6 倍**（叙述句只短 2.8 倍）—— 对白是碎的**主要来源**。

## 二、根因：这一面目前**没有闸门**

三件事叠加，导致"对白写短"没人管：

1. **档案里没有这个量**。`style/stylometry.py` 的 `FEATURES`（21 个）里有
   `句长均值 / 句长CV / 句长p90 / 短句占比 / 长句占比 / 段长CV / 段均句数 /
   对白字占比 / 对白段占比 / 纯台词段占比 / 各类密度 / 四字格 / 短串 / 虚词` ——
   **全部是段落级或全文级，没有"对白句长度"**。没有量 ⇒ 没有基线 ⇒ 没有闸门。
2. **形态校正只在段落级动手**。`style/form.py` 把"光秃秃一句台词"的**段**
   并进它前面那段叙述（改段落边界，一个字不新增）—— 它能让"纯台词段"变少，
   但**不会把一句短对白变长**。
3. **句长闸门量的是段落整体**。`style_rewrite` 的触发条件是段级句长偏离
   （句长 < p10 / 句号密度 > p90），一段里全是短对白时，段级均值可能仍然"正常"。

⇒ 「对白写得碎」在**句级**这一面是**无管区**。项目此前盯住的是**段落级**
的"纯台词段占比"（目标 21% / 逐单元口径），那条线其实**已经达标**
（Flash 27.7% vs 参考书 16.2%），于是"还差 4 个点"这个判断掩盖了句级的问题。

## 三、候选方案

### A. 加特征 + 加闸门（最正规，成本最高）

- 在 `stylometry.FEATURES` 里加 `对白句长中位数`（第 22 个特征），
  在 `style/rewrite` 的触发条件里加一条：偏离参考书该特征的 p10~p90 带 → 触发改写。
- **代价**：特征进档案 ⇒ **档案格式变了**（指纹要变、已存的档案要重算、
  21 个特征的旧档案与新档案不可比）。这是一次**破坏性**的口径变更。

### B. 复用形态校正的**样例机制**（推荐先试，成本最低）

形态校正已经证明「给**形态正确的原文实例**比给统计数字有用」——
实测 Flash 改写把纯台词段 42% → 6%（而四轮**提示层**实验全部在噪声内或更差）。
同一个机制可以用在句长上：

- 从参考书里挑 **对白长句**的正确实例（4 条、每条 ~60 字，和现在的形态样例同规格），
  与现在的「形态样例」**并排**喂给改写提示；
- 目标值仍然取参考书自己的分布（`对白句长 p50` 的逐单元均值 + p10~p90 带），
  过冲保护沿用现有的（不许把"偏短"改成"偏长"）。

- **代价**：0 次额外模型调用（复用已有的改写环节），但**要动提示模板**，
  且形态样例与句长样例**挤在同一个 prompt 里**可能互相干扰 —— 需要实测。

### C. 只改基线提示（成本 0，但历史经验是无效的）

在文体基线里加一行"对白用长句，一句话说完整"。
**但项目已有硬证据**：形态指标**提示层挪不动**（四轮实验全在噪声内或更差）。
句长是另一把尺，未必同样，但先验很差 —— 只作为 B 的对照跑。

## 四、验收口径（不管选哪个方案都用同一把尺）

1. **对白句 p50** 落在参考书自己的 p10~p90 带内（不许过冲）；
2. **纯台词段占比**（逐单元口径）不许因这次改动而**变差** —— 形态线已经达标，
   不能为了句长把形态打回去；
3. **句长均值 / 段均句数**不许偏出参考书带；
4. 每项改动都要有 **成对真跑**（同提示、同场景、改前/改后各 ≥3 次），
   并如实报出**方差**（本项目反复记的纪律：2 个样本分不出 8 个百分点的差别）。

## 五、要避开的坑

- **别用"整段汇总"口径去比档案**：档案是**逐单元**口径，
  真书逐单元均值 16.2% vs 全样本汇总 24.7%（`form.py` 注释里写着这条）。
- **别拿形态达标当句长达标**：两者是不同尺子，混用会把"偏离"算错。
- **别把"模型写短"当成模型的错**：先确认参考书自己的对白句长分布
  （p50 72 字）——是**我们的提示与闸门**没管这件事，不是模型天生写不出长对白。
