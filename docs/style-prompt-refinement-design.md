# 文风提示词细化:把「数字 + 要求」变成「模型能直接用的东西」

> 状态:**四步全部已实现**(2026-10-26)。第 4 步的形态与原设想不同（见 §2.1）。
> 本文描述**要做什么**与**为什么**;实现期新查到的东西也记在这里(标注「实现期发现」)。

---

## 一、问题

现在的提示词给模型的是两样东西:**一组数字**和**几句要求**。

```
【文体基线】以下数字来自参考语料的统计（每单元约 3000 字），不是形容词，请照着写而不是照着想象：
句长 67±19.1 字（参差度 CV 0.87） · 每段 1.8 句 · 段长 CV 0.97
对白占正文 17.5%（43.2% 的段落含对白）
对白段：典型 61 字 · 纯台词段占 20.8%（只有台词、前面没写动作/神态的对白段）
每千字标点：，67 · 。12.1 · ！0.8 · ？2.5 · …0.2
上限（超出即偏 AI 腔）：比喻 ≤2/千字 · 情绪直陈 ≤0.4/千字 · 段尾拔高 ≤6.3% 的段落
用词粒度：四字格 9.7/千字 · ≤3 字短串占 6.2%
```

```
【叙事手法（每行一种，讲的是怎么写，不是要写的内容）】
人物——用微表情和视线变化表现迟疑、戒备或关切；用连续动作呈现高手交锋，不直写招式优劣；……
```

四个缺口:

| # | 缺口 | 现状证据 |
|---|---|---|
| 1 | **角色没有生平** | 档案里关于角色的只有「角色声音词典」（腔调）与 L2 关系网;**没有「他经历过什么」**。KG 的 `kg_character_state` 是**状态**（在哪/伤在哪/想要什么），不是**经历**（做过什么、按什么顺序）。 |
| 2 | **基线只有均值与上限，没有区间** | `stylometry.describe()` 渲染的是 `均值±std` 与若干**单边上限**（p90）。档案里 `p10/p50/p90` **本来就有**（`stylometry.py:643-645`），只是没渲染成区间。 |
| 3 | **提示词没规范化** | system 块是散文式长段（真跑实测 1709 字），块内无固定句式，模型得自己找重点。 |
| 4 | **要求是干巴巴的** | 「用微表情和视线变化表现迟疑」——模型读得懂字面，学不会怎么做。 |

## 二、四条改动

### 1. 角色生平（**已实现，但形态与当初设想不同**）

**原来的设想**：新增抽取 —— 按角色抽「他做过的事」→ LLM 总结成人物弧线 → 进角色层档案。

**实现期查清的事实**（这改变了做法）：

1. **「关键经历」字段早就在档案里了**，质量不差（实测陆长风 6 条：湖畔下潜、
   寻红薯、赠佛钵、托付李当心、气运被窃…），**LLM 总结这一步不需要新做**。
2. **但它进不了提示词** —— `render_character_profile` 的门禁要求
   `evidence_status == "located_extracts_not_semantic_proof"`，
   而这个字段只有**带 claim 账本的新档案**才有。老档案缺这个键 ⇒
   默认值 `unverified_legacy` ⇒ **整个角色档案渲染成空串**。
   ⇒ 实测《北荒刀歌》 8 个角色：回填前 `render_character_profile` 返回**空字符串**。
3. **而且很多角色压根没有档案** —— characters 层只抽前 N 个主要角色
   （北荒刀歌 8 个：陆长风/陆崇/赵磐石/楚惊蛰/陆北枝/小宁/裴长卿/赵青锋），
   **老周不在里面**。用户选了他，他有**声音**却**没有档案** ⇒ 档案回填也救不了
   （没有条目可回填）。

⇒ **最终做法**（两块，互补）：

| 块 | 做什么 | 模型调用 | 解决 |
|---|---|---|---|
| **证据回填**（`style/bio_evidence.py`） | 给**已有**档案补证据，让它过门禁 | 0 | 「有档案但进不去」 |
| **生平时间线**（`roleplay/bio.py`） | 给**没有档案**的角色，按章挑出他**在场**的事件句 | 0 | 「压根没档案」 |

**证据回填怎么核**（不放宽门禁）：字段值是**改写过的总结**，claim 级那道判据
（value 必须逐字出现在摘录里）核不了 ⇒ 走**字段级事实核验**：
把字段值切成 3~4 字实词 n-gram，看它能不能在**有他出场的行**里定位到。
定位到 ⇒ 这条经历的核心事件在书里存在 ⇒ 放行，并把定位到的**原文段落**一起给
（这就是「配合检索」）；定位不到 ⇒ **丢掉这条字段**。

实测（《北荒刀歌》 8 个角色 × 32 条经历）：**32/32 条至少命中一个 ≥3 字的事件短语**
（「九岁奉召」「一字十文」「徽山赵」「被陆长风」）；覆盖率中位 39%
（总结句改写得多，不能要求高）。核不上的字段被丢掉（实测丢 4~6 条）。

**只在「有他出场的行」里找**（不只为了准，也为了快）：
语料从 72838 行缩到每角色约 900 行 ⇒ 实测 **35s → 2.6s**；
而且定位更准（短语必须跟他同框）。

**时间线怎么挑事件**：每章里含他名字的行中，取**完整句**（引号配对 + 以句末标点结尾
+ 12~50 字 + 有动作动词 + 名字**不在引号里**）⇒ 名字出现得越早越优先（更像「他做的事」）。
实测老周：第13章「老周还不忘转头咧嘴一笑，伸手比划了一下与陆长风身高差不多的高度，
大概意思就是我是这样高的高手。」

**怎么进提示词**：
- **角色对话**路径：档案（回填后）+ 生平时间线 + 说话方式 + 检索片段 ⇒ 一起给；
- **写正文**路径：档案（回填后）进 L2 角色档案块。

**边界**：角色生平是**角色层** ⇒ 原创路径**不给**（参考书角色不该进用户的小说），
与「角色声音词典」同一处理。

**代价**：零模型调用；档案渲染限长 400 字/角色（实测不限长时是 **1117~2005 字/角色**，
8 个角色就是上万字 ⇒ 挤爆提示词、摊平权重）。

### 2. 文体基线:均值 + **上下限保底**（纯渲染，零模型调用）

**改成**（每项一行，区间在前、均值做参考）:

```
【文体基线】以下数字来自参考语料的统计（每单元约 3000 字），不是形容词。
【句长】一句 48~92 字（参考书自己落在这一带，均值 67）
【每段句数】1.3~2.4 句 · 段落长短要参差（CV 0.97）
【对白】对白占正文 14%~22%（约 15% 的段落含对白）
【对白段】典型 45~75 字 · 纯台词段（只有台词、前面没写动作/神态）不超过 28%
【标点】每千字：逗号 58~76 · 句号 10~14 · 问号 1.8~3.2
【上限（超出即偏 AI 腔）】比喻 ≤2/千字 · 情绪直陈 ≤0.4/千字 · 段尾拔高 ≤6.3% 的段落
【用词粒度】四字格 9.7/千字 · ≤3 字短串占 6.2%
```

**要点**:
- 区间 = 语料自己的 **p10~p90**（不是拍脑袋，也不是 ±std）——「落在这一带就算合格」。
- 单边上限类指标（比喻/情绪直陈/段尾升华）**保持上限形态**（它们是「越少越好」，给下限没意义）。
- **可自动验收**:区间与 `stylometry.band_check()` 用的是同一对 p10/p90 ⇒ 提示词说的区间 = 验收用的区间（不多说，做到能核）。

**实现期发现:不是所有指标都给区间。** 第一版给「对白字占比」也加了区间，
渲染出来是 **2.7%~35.8%** —— p10~p90 覆盖了九成样本，**模型怎么写都合格**，
等于把一句有用的数字变成废话。感叹号/省略号更极端：区间下限是 0（多数段落 0 个）。

⇒ 纪律（同 AGENTS.md「分位点在长尾分布上退化 ⇒ 看形状不看分位点」）：
**连续型**（句长、每段句数、标点密度）给区间；**比例型/稀疏型**只给均值或上限。

渲染出来的样子（《北荒刀歌》真档案）：

```
【文体基线】以下数字来自参考语料的统计（每单元约 3000 字），不是形容词，请照着写而不是照着想象。
带区间的指标：**参考书自己就落在这一带**，落在里面就算合格（不必取均值）。
【句长】一句 45~92 字（均值 67） · 参差度 CV 0.87
【每段句数】1.3~2.5 句（均值 1.8） · 段落长短要参差（CV 0.97）
【对白】对白占正文 17%（43% 的段落含对白）
【对白段】典型 61 字 · 纯台词段（只有台词、前面没写动作/神态）不超过 20.8%
【标点】每千字：逗号 59~75（均值 67） · 句号 8~17（均值 12） · ！ 0.8 · ？ 1~5（均值 3） · … 0.2
【上限（超出即偏 AI 腔）】比喻 ≤2/千字 · 情绪直陈 ≤0.4/千字 · 段尾拔高 ≤6.3% 的段落
【用词粒度】四字格 9.7/千字 · ≤3 字短串占 6.2%
```

**已有，不动**:档案的 p10/p50/p90 已经在算（`stylometry.py:643-645`），只改渲染。

### 3. 提示词规范化（纯渲染，零模型调用）

**固定句式**:`【标签】内容`，一块一行一事。

**三条规矩**:
1. **不重复**:system 里有的，user 尾部提醒里不再重发（现在 constraints 块与 system 块各自列角色名单，是重复的）。
2. **总量上限**:system 的文体/手法部分整体限长（建议 1200 字），超了按「离目标越近越先留」裁。
3. **块间空行固定**，便于人读与 diff。

**为什么值得做**:模型的注意力有限；一段 1700 字的散文里，模型对每条要求的权重是平的 ⇒ **「重点」就等于「没重点」**。分块 + 标签是把它变成可检索的清单。

---

### 4. 要求带案例（**材料已经在档案里**，只差渲染）

**关键发现**:叙事档案的**每条规则后面已经附了 ≤20 字的原文证据**
（`narrative.py:758` 的抽取要求 + `_strip_evidence`）。
渲染时把证据剥掉了——因为**证据是参考书的原句，含专名，会把参考小说的人物带进用户的小说**
（实测北荒刀歌注入前 3 条时泄漏 **255 处**人名，剥掉后 0 处）。

⇒ **案例材料现成**，要做的是:
1. 从规则里**取出**证据（剥之前）；
2. **脱敏**（复用 `style/entities.Redactor`：专名换等长占位符 `＃＃＃`，保留句法不动）；
3. 作为**例句**渲染在要求后面。

```
人物——用微表情和视线变化表现迟疑、戒备或关切。
  例：＃＃＃那只手在袖口里动了一下，又停住。
```

**约束**:
- 每条**最多 1 句**例句（≤25 字），否则提示词膨胀。
- 例句必须**来自语料**（不编）⇒ 沿用现有的证据账本纪律。
- 脱敏后仍含人名/地名的一律**不渲染**（宁可没例子）。
- 与「反向禁忌」一致:那边给的是**禁用词的真实例子**，这边给的是**手法的真实例子**。

**实现期发现:脱敏一道闸不够，必须两道。**

专名表是「**PMI 召回 + LLM 判定**」的产物 ⇒ **高精度但不保证覆盖**。
实测（北荒刀歌真档案，267 个专名）：
- 渲染后仍漏 **1 个**（「绣冬刀」，出现在**规则正文**里 —— 这是既有泄漏，不是例句带来的）；
- 例句里还有「刻有耶律慕容四字」这种**表里根本没有的名字** ⇒ 「脱敏了就安全」这个前提**不成立**。

⇒ 加**第二道闸**：**判定之前**的 PMI 候选集（高召回、含虚词）。
例句里命中任何候选 ⇒ **整句丢掉**。

- 候选集算一次要扫全库（北荒刀歌 122 万字 ⇒ 601 个候选）⇒ 必须**存进专名表**
  （表本来就按书缓存）⇒ `entity_judge` 现在把 `candidates` 一并存进表里。
- **代价是误杀**：候选集含虚词，会连带拦掉「即便 / 眼神 / 转身 / 嘴角」这类普通词。
  实测存活率 **672 / 1576 = 43%** ⇒ 每维挑 2~3 条**够用**，而漏专名的后果大得多。

**实测结果**（真档案，两道闸都开）：**28 条例句，PMI 候选命中 0、表内专名命中 0 —— 零泄漏**。
例句长这样：

```
面纱遮掩看不清容颜          ← 用外表遮蔽表达内心
俏脸涨红                    ← 外貌形变捕捉情绪
不给，她是我的              ← 短段落在关键节点
白虹横江，潮头也随着推进渐次拔高   ← 空间由远及近
就像一只匍匐在草原上的巨大金色蜘蛛  ← 象征性外观
```

**一个要留意的张力**：「用象征性外观把权力中心具象化」这条要求，它的例句**本身就是比喻** ——
而【反向禁忌】里写着「比喻 ≤2/千字」。给了一个比喻例句，可能反过来鼓励比喻。
⇒ **这一条要单独 A/B**（不能只看总量指标，例句诱发复读与偏好偏移是指标测不出来的）。

**代价**:零模型调用，但要动 `_prompt_form` 的取法 + 一次脱敏（Redactor 已存在）。

## 四、怎么验（沿用本项目的规矩）

- **A/B**:同一上下文、同一模型、同一生成参数，**只换提示词块**；n≥3，报告组内方差。
- **看什么**:`style_distance` 的主导项（句号密度 z）+ 句长均值 + 总分 `mean_abs_z`。
- **不只看指标**:提示词改动要**人读一遍输出**（案例会诱发复读，这是指标测不出来的）。
- **归因要单变量**:一次只动一块。

## 五、边界与风险

| 风险 | 应对 |
|---|---|
| 案例诱发**复读参考书情节** | 例句只取**单句**、脱敏、且不与「角色/情节」相关；生成后走现有的复读检测（`_dedup_before_commit`） |
| 例句让提示词膨胀 | 每条 ≤1 句 ≤25 字；总量上限（§2.3） |
| 角色生平泄漏参考书剧情 | 角色层只给**被扮演/在场**的角色；原创路径不给（与声音词典同处理） |
| 「区间」变成新的指标打架 | 区间与 `band_check()` 同源，不新增第二套尺子 |
| 规则证据本身是**错的**（LLM 提错） | 沿用证据账本：**渲染前先核证据是否真在语料里**（已有删除测试）；核不过就不渲染例子 |
