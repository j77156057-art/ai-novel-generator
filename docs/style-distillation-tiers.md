# 文风蒸馏档位划分与实测对比

> 目的：把风格蒸馏（narrative）按能力分档，用于按场景选档。
> 数据来源：各版本在参考语料上的真实 `build-narrative` 落库结果（`test_e2e*.db` 存档），非估算。
> 测试模型：智谱 glm-4-flash（免费档）。语料 1 为主语料（见下）。

## 分档原则

真正有档位意义的是三次能力跃迁：**v3 → v5 → v7**。
中间 v6.x 全是修 v6 质量缺陷的补丁（占位符、伪角色、角色名截断），
不构成独立档，归入 v7 档的前置。

| 档位 | 版本 | 定位 |
|---|---|---|
| **第一档（完整档）** | v7 | 生产用。14 维度 + 文风漂移 + 角色名语料自证归一 |
| 第二档（平衡档） | v5 | 维度齐但角色名有噪声，适合试跑/中篇 |
| 第三档（快速档） | v3 | 维度少、成本低，适合短篇/冒烟 |

> **底座（不分档，任何档都带）**：L1 数字档案（stylometry，零 LLM）、
> P0 风格样例注入、P1 生成后 AI 味告警、反向禁忌提取。

## 三档能力对比

| 能力项 | 第一档 v7 | 第二档 v5 | 第三档 v3 |
|---|---|---|---|
| 叙事维度数 | 14 | 14 | 11 |
| 节拍序列（一场冲突的 N 步写法） | ✅ | ✅ | ❌ |
| 高频场景模板（环境/站位/动作链/基调） | ✅ | ✅ | ❌ |
| 潜台词模式（反话/转移话题/沉默） | ✅ | ✅ | ❌ |
| 文风漂移分析（早期 vs 晚期） | ✅ | ✅ | ✅ |
| 角色名归一化（小落→安小落、宫爵→南宫爵） | ✅ 语料自证 | ❌ | ❌ |
| 采样策略 | 按百分比 + 场景均衡 + 对话优先 | 固定 30 章 | 固定 30 章 |
| 角色声音提取 | 主要角色逐个 + 配角分批，针对性检索 | 针对性检索 | 单批浅层 |
| 伪角色/占位符清洗 | ✅（虚词黑名单 + 频率自证） | 部分 | 无 |

### v7 角色名归一化效果（核心差距）

图谱（LLM 逐块抽取）里 513 个角色节点混着高频虚词和分词截断。
v7 用语料词频的**包含关系自证**清洗，不依赖词表：

- 规范角色名 19 个，全部是真角色：安小落/南宫爵/夏诺/莫泽修/何萱萱/蒋曼曼/
  莫雨蝶/钟姨/冷月/文静/南尊义/韩明秋/夏浅/唐甜甜/郑楚桥/南总/林玲/莫母/秦岚
- 别名映射 12 条：小落→安小落、宫爵→南宫爵、莫泽→莫泽修、何萱→何萱萱、
  蒋曼→蒋曼曼、莫雨→莫雨蝶、南尊→南尊义、唐甜→唐甜甜、郑楚→郑楚桥、
  安小→安小落、南宫→南宫爵、夏诺柔→夏诺
- 归判据实测分离度：真截断 ≤1.1%，真名 ≥67%（完全分离，无误判）

对比：v5/v3 无此能力，输出里混着「小落/宫爵」等截断名和「相信/冷声/时间」等伪角色。

### 跨语料角色名归一化：核心成立，但暴露局限

**做得好的**：主要角色全部识别为真实全名——许七安/李妙真/元景帝/金莲道长/
李灵素/宋廷风/许平峰/许铃音/魏渊/怀庆/临安/王妃，且关系动态准确
（元景帝对下属命令式、对大臣询问式、对许七安试探式）。

**暴露的局限（大靖专属，v7 未覆盖）**：

1. **同一人的多种切分未合并**：`金莲道长`(1349) / `金莲道`(1361) / `莲道长`(1472)
   三者互不为子串，包含判据合并不了；后缀扩展判据被「道长」停用挡住。
   导致角色声音里「金莲道」和「莲道长」分裂成两条，代表台词张冠李戴。
2. **称谓混入**：`魏渊` 和 `魏公`（魏渊的官称）各占一条，台词重复。
3. **角色名池膨胀到 421 个**：大靖图谱 2644 节点，`speaking` 标志几乎全 true，
   候选池条件「会说话 ∪ 高提及」几乎不过滤，混进大量虚词/片段
   （武夫/云州/江湖/白衣/高手/公主/公子/师父/皇后/罗汉…）。
   语料 1 的 `speaking` 区分度高（39/513），大靖失去区分度。

> 这三条是大靖语料的特性（图谱抽取器行为 + 称谓密度），不是 v7 在语料 1 上的回归。
> 语料 1 上 v7 角色名池 19 个、全部干净；大靖上池子 421 个、主要角色对但有分裂。
> 属于「已知局限」，修法见下。

### 局限的修法方向（未实现）

- 称谓后缀（道长/公子/师父/国师/陛下）不作为名字末字，需单独建称谓词表，
  把 `金莲道+长`、`莲道长` 归并到 `金莲道长`
- 候选池不能只靠 `speaking`，需加「名字 + 言说动词邻接率」二次过滤
  （真角色名后紧跟 道/说/冷笑，虚词不跟）
- 称谓前缀（魏公/许郎/国师）单独建映射表归并到本名

## 选档建议

- **快速档（v3）**：短篇、冒烟、只验证管线通不通
- **平衡档（v5）**：中篇试跑、对角色名噪声不敏感的场景
- **完整档（v7）**：生产环境。角色名准确、14 维度齐、按百分比采样覆盖面可控

## 备注

- 各档产出都落到 `projects.style_narrative`，指纹含 `narrative_version`，
  改提炼逻辑升版本号即可让旧缓存失效。
- rejected 是证据验证 + 逐字复制检测拦掉的伪规则数，反映该次 LLM 输出的干净程度，
  非档位能力指标。
