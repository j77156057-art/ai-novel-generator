## 3. v2.225 失败详情

```
[upload] dt=71.1s novel_id=1 (11,343,206 bytes, 5.9MB)
[B] 启动 generate_loop 1 段 (zhipu + 全本 588万字 + max_tokens=8192)
[B] ERR: timed out (1800s client timeout)
[C] total=0
```

**失败原因分析**：

- `fit_profile_v2` 跑全本 588 万字，**阻塞 > 30 min**（30x 数据量于 30 章 v2.224）
- client timeout 1800s + background timeout 1800s 都不够
- 智谱 1 段 ~5-15 min + fit profile 30-60 min = **整体需要 40-75 min**

**为什么不修**：

- 「全本 100% 蒸馏」**不是之前会话的蒸馏档位**（之前会话是 15% 完整档）
- v2.225 跑的「100% 全量」 = 自创档位 = **工程边界**（fit profile 30-60 min + 智谱 5-15 min + DB 落库 1-5 min = 40-75 min）
- 工程成本超过 client timeout 上限（**典型 client timeout 上限 30-60 min**）
