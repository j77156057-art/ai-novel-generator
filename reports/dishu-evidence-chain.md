# 地书 / 玉石小镜：持有与权属证据链

状态：只读取证，未改任何表、未改 `ITEM_ALIASES`、未重抽。
数据源：`backend/novel_dev.db` 的 `novel_chunks`（novel_id=5）与 `backend/data/generated.db` 的
`kg_item_holding` / `kg_item_instance` / `kg_holding_story_segment`。

## 0. 口径

- **排序按故事时间**，不按章号。`ch451`、`ch747`、`ch773` 是后面章节里的**追述**，讲的是上古与
  ch51 之前的事，所以排在链条前段；「叙述章」与「事件时间」在每一环里分开写。
- **置信度**是「这条结论被正文支撑到什么程度」，不是「库里的行对不对」。库里行与正文冲突时，
  单列成缺口，不改数据。
- **反证**只写「什么样的原文会推翻它」，不写「可能不准」这种空话。
- 章号一律用正文的 `chapter_no`；`valid_from=0` 是回溯占位，**不是第 0 章**。

## 1. 链条主体

### E01 炼制：道尊熔神印成地书

- **叙述章**：ch451（事件时间：上古）
- **原句**
  > 【在上古时代，地书象征着山川，天宗的案牍库里，有一本《九州神灵录》，上面记载，上古时代的九州，遍布着山神、河神等神灵。他们凝练九州山川地脉的力量，将之化为山神印、水神印。
  > 【某一年，道尊斩灭“九州神灵”，将九州所有的山神印和水神印，熔炼成了一件至宝，这件至宝就叫做“地书”。】
- **辅证**：ch773「地书的器灵就是道尊的元神」；ch73 打更人档案「地书是上古至宝，来历无法考证，只知是那位出身年代无法考证的道尊遗留」。
- **结论**：地书是**人为熔炼**的至宝（九州神灵的神印为料），器灵是道尊元神。它不是天生法宝。
- **置信度 0.85**
- **反证**：ch73 档案另写「此类上古至宝，多是天地孕育而生，非人力能炼」——这句泛论与 ch451
  直接冲突。要推翻 E01，只需证明档案那句是针对地书本体的定论而非通例；目前 ch773「道尊炼地书」
  与 ch451 互相印证，判档案那句是泛论。
- **库内行**：无。`kg_item_holding` 只记「谁在什么章持有什么」，没有「物品来源」这个维度；
  `kg_item_instance` 只记同名多实物，记不了炼制。

### E02 碎裂：地宗把地书击碎成九块封镇

- **叙述章**：ch773（事件时间：上古，炼制之后）
- **原句**
  > 【九：没错，地书的器灵就是道尊的元神，地书炼成当日，发生了非常可怕的事，地宗古籍中记载：地书成妖，噬生灵，吞万物，本宗弟子伤亡殆尽，将地书碎九块，封镇妖灵！】
- **结论**：九块是**地宗主动击碎**的结果，目的是封镇器灵，不是战损或意外。这一条决定了后面
  「碎片」是制度性存在，不是残片。
- **置信度 0.85**（转述地宗古籍，二手）
- **反证**：若出现「九块乃雷劫/天谴所致」或「地书自碎」的原文，则推翻「人为击碎」。
  ch768「七块玉石小镜聚合……缺了一角的方形玉盘」与「九块」自洽，未见矛盾。
- **库内行**：无。理由同 E01：碎裂是物品沿革，不是持有段。

### E03 分发：金莲把九块分赠，七人组成天地会

- **叙述章**：ch76（事件时间：ch51 之前，跨度不明）
- **原句**
  > 老道士摇摇头：“我已经有了。”
  > 他袖子里滑出一面玉石小镜，与许七安怀里那个一模一样。
  > “这是贫道那师弟执掌的玖号碎片，如今总算物归原主。至于施主那面，就当是贫道送你的谢礼。”
  > “地书碎片总共九块，贫道分别赠予了不同的人。施主也是贫道相中之人。”
  > “那七个不同的人，组成了天地会。”
- **结论**：金莲是分发者；至少七块进了天地会（七个受赠者＝群成员），第八块（三号）给了许七安，
  第九块（九号）原由其师弟紫莲执掌、ch76 被金莲收回。
- **置信度 0.8**
- **反证**：「七个不同的人」＋「九块」之间差两块（金莲自己、紫莲的九号）。若正文另有第八个受赠者，
  则「七人」口径要改；若九号在 ch51 前已归金莲，则「师弟执掌」只是 ch76 之前的暂态。目前两说都能
  自洽，故不给更高置信度。
- **库内行**：无。分发是一次性事件，且受赠者多数未实体化（`owner_id` 只能为空），表里只能记
  「三号在谁手上」，记不了「谁把哪块给了谁」。

### E04 空缺期：九块里只有二号、七号有主

- **叙述章**：ch747（事件时间：八号入群时，远早于 ch51）
- **原句**
  > 【八：当初我持有地书碎片时，九块碎片只有二号和七号有主，其他碎片的主人空缺。】
- **结论**：八号持有碎片的那段时间，九块中只有二号、七号已有归属，三号当时**空缺**——与
  「金莲 ch51 才把三号交出去」自洽。
- **置信度 0.5**（追述；「当初」没有给锚点章；说话人八号 ch747 才现身，资历无法交叉验证）
- **反证**：这句本身反证库里 `id=12`。若「空缺」把金莲手上的三号也算进去，那 `id=12` 的
  `owner_name='金莲师兄'` 严格说是「待赠暂存」，不是「持有者」。正文没有一句写金莲「拥有」三号，
  只写他「分别赠予」。这是 `id=12` 置信度只有 0.5 的原因（行内 `confidence` 也是 0.5）。
- **库内行**：`kg_item_holding.id=12`（金莲 custody `[0,51)`，`evidence_chapter=51`）。反证见上。

### E05 入手：ch51 投壶赢后二选一，镜子到许七安手上

- **叙述章**：ch51（事件时间：ch51）
- **原句**
  > 老道看了他一眼，镇定的把金锭银锭收了包裹，然后指着最顶端的菩提手串和玉石小镜，笑眯眯道：
  > “公子，二选一。”
  > ……
  > 许七安接过钱囊，又从老道那里取走玉石镜，目送着马车离开。
  > 他收回目光，随意把巴掌大的玉石镜揣进怀里。
- **他是怎么拿到的**：投壶赢的是金银；老道按「规矩」只让他从**菩提手串和玉石小镜里二选一**，
  菩提珠被马车主人买走，他选了镜子。**不是抽中**，也不是别人转赠。
- **当时知不知道是地书**：不知道。ch51 老道自称「老道不知，只知它们在等待有缘人」；ch73 才由
  玖号点明「这法宝又叫做地书」，ch73 许七安才去案牍库查「地书」资料。
- **辅证**（交接性质，三种措辞）
  - ch73 许七安对玖号：「只是当时那位金莲道长与在下说，此乃天地至宝，以黄金五百两的价格兜售于我。」
  - ch76 金莲：「至于施主那面，就当是贫道送你的谢礼。」
  - ch100 许七安对金莲：「您将三号碎片赠予我时，三号碎片被封禁。」
- **结论**：**实物在 ch51 转到许七安手上**，这一点无歧义；**交接的法律性质**（奖品 / 500 两买卖 /
  赠礼）正文自相矛盾，三种说法并存。
- **置信度**：转手 0.95；交易性质 0.5。
- **反证**：若 ch51 之后仍有金莲持有这面镜子的原文，则 E05 推翻。检索 ch51–73，金莲只被转述、
  未再接触实物（ch77 才真人现身）。
- **库内行**：`kg_item_holding.id=12`（金莲段收尾于 51）、`id=32`（许七安段起于 51，
  `evidence_chapter=51`，`evidence` 用的就是「指着最顶端的菩提手串和玉石小镜」那句）。
  `kg_item_instance.id=1`（三号，证据 ch72）。

### E07 ch73 滴血认主：建立联系，不是取得实物

- **叙述章**：ch73（事件时间：ch73）
- **原句**
  > 地书是上古至宝，来历无法考证，只知是那位出身年代无法考证的道尊遗留。
  > 它们有一个共同的特质，就是滴血认主。
  > 他掏出怀里的玉石小镜放在桌上，佩刀出鞘两寸，指肚在刀锋轻轻按压。
  > 殷红的鲜血立刻沁出，许七安抹在玉石小镜的表面。
  > 滴血认主后，玉石小镜与他产生了某种奇妙的联系。玄而又玄的归属感。
- **结论**：认主发生在**拿到镜子 22 章之后**，动作是「把血抹在镜面」，效果是「建立联系 / 获得
  传讯权限」，**不是第一次取得**。ch74 陆号说得更直白：「直到你滴血认主，建立了与我之间的联系。」
- **置信度 0.9**
- **反证**：「归属感」字面像所有权，若后文出现「认主即易主」的表述，`own` 层要重写。实际
  ch74 陆号紧接着仍要求他「将地书碎片归还天地会」，说明认主≠所有权。
- **库内行**：**无独立行**。认主是「未入群 → 入群」的状态切换，表只有 `custody` / `own` 两种
  持有关系，没有「建立联系」这个维度；硬塞进持有段会造出一段假的转移。

- **库内行**：`kg_item_holding.id=15`（`own` / 天地会 / `[74,∞)` / `instance_id=NULL`）。
  `instance_id` 为空是刻意的：这一条挂**整体法宝**，不挂某一块碎片。

## 3. 分层

### 3.1 整体法宝

- `own` 归**天地会**，`[74,∞)`，`instance_id=NULL`（`id=15`）。
- **为什么个人的认主/保管不是所有权**——按正文措辞排：
  1. 「托付」：ch77「我才真正放心把地书**托付**与你」——托付的是保管，不是产权。
  2. 「归还」：ch74「我希望你能将地书碎片**归还天地会**」——若已归个人，无「归还」可言。
  3. 「只有你能回复」：ch74 魏渊「镜子已经滴血认主，**只有你能回复**」——认主绑定的是**通讯权限**，
     不是物主身份。
  4. 「舍弃碎片，转赠给你」：ch74 陆号描述金莲的行为是「舍弃」——他放弃的是持有，不是所有权。
- 这条 `own` 的置信度只有 0.6，原因见 E08 反证（许七安自称「私有物」、地宗称「我宗至宝」）。

### 3.2 单块碎片

- `custody` 记在个人名下，用 `instance_id` 区分编号。三号 = `kg_item_instance.id=1`。
- 三号链（首尾相接，无并行开放段）：

```
[0,51)    金莲师兄   custody  id=12
[51,105)  许七安     custody  id=32
[105,107) 许新年     custody  id=33
[107,∞)   许七安     custody  id=34   ← 起点应为 108，见 G3
```

- 链条本身没有重叠、没有空洞；但 `[51,105)` 把 ch74–76 魏渊的短暂持有吞掉了（G2），
  `[107,∞)` 的起点比正文早一章（G3）。

### 3.3 两条线为什么不互相关闭

`own` 与 `custody` 是两条独立时间线：ch74 起权属归天地会，但实物一直在个人手上流转
（三号：许七安 → 许新年 → 许七安）。因此 `own` 只有一条开放段，`custody` 可以有任意多段，
两者不互斥、不互相截断。
