# 复盘：一次批次失败 = 一百个真名被判成「不是专名」（2026-10-30）



> 这份文档记的是**实测**过程与数字，不是设想。

> 触发它的不是「模型判错」，是**判定批次失败被静默降级**。



## 发现



18 题盲评包出完后做泄露自查，发现**第 1 题的人类侧原样留着两个人名**，

而我们那一侧是 `＃＃` ⇒ 盲评当场作废（评者看见名字就知道哪边是出版物）。



查判定缓存（`blind_names_human.json`）：



| 现象 | 数值 |

|---|---|

| 缓存里的候选总数 | 1896 |

| 判成**专名**的 | **16** |

| 判成「不是专名」（null）的 | 1880 |

| null 的分布 | **成片出现**（422 / 395 / 231 / 211 / 205 … 连成大段） |



「齐夏」「云瑶」「童姨」「杨间」这些**明显是人名**的词也在 null 段里 ——

一个正常的逐词判定不该这样。



## 根因（探针实测，不是猜的）



```python

verdicts[w] = got.get(w)      # 模型没返回的词 ⇒ 记成 None

```



`_judge_batch` 在**回包解析不出来**时返回 `{}` ⇒ **整批 100 个词**都被记成

「判定为 null」。而 null 的含义是「这个词**不是**专名」。



回包为什么解析不出来？provider 在输出撞上 `max_tokens` 时**只告警、照常返回半截内容**

（`finish_reason=length`）—— 半截的 JSON 数组 `json.loads` 直接失败 ⇒ 整批蒸发。



探针实测：100 词一批**有时**回包完整（`finish_reason=stop`），**有时**被截断 ——

**概率性**发生，所以前 6 题的小包侥幸没中招。



⇒ **一次批次失败 = 100 个真名被记成普通词，还被永久缓存下来。**



## 修法：三层



1. **判定层不许把「没判出来」写成「不是专名」**

   - 新增 `UNJUDGED` 状态，与 `None` 严格分开；

   - 批次失败/截断 ⇒ 拆小批重试（30 → 15 → 7 → 3 → 1）；

   - 拆到 5 个词一批还判不出来 ⇒ 标 `UNJUDGED`，**不进缓存**；

   - 判定缓存带版本号，旧格式整份作废。

2. **脱敏层 fail closed**

   —— 只要有一个候选词处在 `UNJUDGED`，抛 `MaskingIncomplete` ⇒ 整包作废、题面不发。

3. **新增第六道闸门「题面级专名复查」**

   —— 脱敏后把**成段题面**再读一遍，把还是专名的词挑出来补遮；

   挑到的补遮后重查（≤ `RESIDUAL_ROUNDS` = 7 轮）；清不干净 ⇒ 整包作废；补遮 >5% ⇒ 整包作废。



配套：判定用**独立 provider 实例**（`thinking_off=True`、不装成 Writer 单例）；

脱敏的判定批次从 100 降到 30。



## 重出这一版的实测数字（干净语料臂 30 段 → 18 题）



| 项 | 数值 |

|---|---|

| 逐词判定候选 | 我们侧 599 个 / 人类侧 1896 个 |

| 判成专名 | 我们侧 11 个 / 人类侧 42 个 |

| **题面复查补遮** | **5 个**（二虎、林檎、红塔山、老四、齐＃＃）—— 这 5 个**逐词判定全漏了** |

| 复查轮次 | 第 1 轮 4 个 → 补遮 → 第 2 轮 1 个 → 补遮 → 第 3 轮 0 个 |

| 补遮占正文 | 0.1%（远低于 5% 的作废线） |

| 脱敏痕迹密度 | 我们 3.77 / 人类 5.61 个井号每百字（比值 1.49，未触发 2.5 的泄露线） |

| 自检结果 | `blind = true`，理由为空 |



**这 5 个补遮就是第六道闸门的价值**：它们全是真人名（不是普通词），

逐词判定在「一堆垃圾候选里挑名字」时把它们判成了普通词 ——

**换成「读正文、报出还是专名的词」就全抓到了**。



## 交付前的三条独立口径



| 口径 | 查什么 | 结果 |

|---|---|---|

| 判定名残留 | 42 + 11 个判成专名的词逐个回查题面 | **0 处** |

| 题面级复查（新 provider、无缓存） | 把交付的 `blind_samples.md` 整份再读一遍 | **0 个** |

| 排他 + 人名形状（**完全不用 LLM**） | 本书高频、别的书里几乎没有、且是人名形状的词 | 47 个命中，**逐个看上下文全是普通词**（时间/空间/厉鬼/关押厉鬼…），**没有一个是专名** |



## 残余风险（写明，不粉饰）



像「厉鬼复苏」「极道万岁」这种**书里的标志性短语**还会留在题面里 ——

它们不是专名，判定链路按设计不会动它们。

⇒ 脱敏挡得住名字，挡不住「这句我读过」。



## 教训



1. **「失败」和「否定」在数据里必须能分开。** 这一版把两者都编码成了 `null`，

   于是「没判出来」变成了「不是专名」—— 一个**失败被存成了事实**。

   ⇒ 任何「判定/检测」的结果集，都要能表达「不知道」。

2. **缓存会固化错误。** 判定结果按词缓存本来是为了省钱；

   一旦把失败写进去，它就变成了**永久的**判决 —— 而且没有任何症状。

   ⇒ 缓存要带版本号；失败的结果不进缓存。

3. **闸门要独立于被闸的那条链路。** 前五道闸门（年代、密度、对称性…）全都没抓到这次泄露 ——

   因为它们量的都是**痕迹的统计特征**，而泄露是**逐词的事实**。

   ⇒ 复查那一遍必须**换一条链路**（逐词判 → 读正文）。

4. **概率性失败比确定性失败危险。** 这次是「有时截断」——

   小包（6 题）侥幸没中招，大包（18 题）中了。

   ⇒ 越是「一次性发出去、错了当场作废」的产物，越不能靠运气。

5. **上下文不是万能药。** 探针里给候选词附上原文语境，`楚天` 反而从 `character`

   变成 `null`；单独判 5 个词比混在 100 个里判更准。

   ⇒ 修法不是「加上下文」，是「**别把失败当成否定**」。

# 第二次作废：题材指纹（2026-10-31）



## 症状



第一次（专名漏遮）修完、18 题包出完、交接夹都给主人之后，主人只读了一两题就退了回来：



> 「这个题还是不行，一个厉鬼的，另外一个不知道什么题材，

> 那么只需要判断一两个，根据题材大概都知道哪个是人写的，哪个是 ai 写的了」

>

> 「要么就直接打乱，每个都是从乱七八糟的什么题材都有，

> 这样就没办法靠题材分辨了」



⇒ 泄露的不是**名字**（名字已经全遮了），是**题材**：

人类侧那本满篇「厉鬼 / 复苏 / 规则」，我们侧是都市市井悬疑。



⚠️ **年代闸门全绿也没抓到** —— 它只分了「古风 / 现代」两桶，而这次是**同代不同题材**。



## 实测：词表口径判题材不可信



在 18 本本地语料上逐词统计「每个标记词出现在几本书里」：



| 标记词 | 出现在几本书（共 18 本） | 判定 |

|---|---|---|

| 剑 / 刀 / 江湖 / 将军 / 师父 / 师兄 | 13–18 本 | 噪声（网文通用词） |

| 系统 / 宿主 / 觉醒 / 强化 / 超凡 / 奖励 / 技能 | 11–17 本 | 噪声 |

| 掌柜 / 伙计 / 摊子 / 巷子 / 楼道 / 铺子 / 水泥 | 11–17 本 | 噪声 |

| 厉鬼 / 复苏 / 违规 / 通关 / 逃脱 | 12–18 本 | 噪声 |

| 供销社 / 工分 / 粮票 / 个体户 / 搪瓷缸 | 0–1 本 | 题材专有（可用） |

| 驭鬼者 / 鬼域 / 邪祟 / 收容所 / 人皮纸 / 生肖 | 1–7 本 | 题材专有（可用） |



⇒ 用含噪声词的旧词表判题材，**18 本里 9 本判错**（现代都市小说被判成古风武侠；

古风客栈场景被判成都市市井 —— 古风书里的「小伙计」也命中了市井词表）。



⇒ **判据换成「模型读正文判题材」**（闭集 9 类 + 「其他」），

词表只留**粗筛**（省模型调用）。



## 实测：三条口径



| 口径 | 怎么定 | 为什么 |

|---|---|---|

| 两侧都没露题材指纹 | 距离 **0** | 原来算 1.0（「毫无共同点」），与事实相反 —— 后果：都市臂的人类侧整本没有题材标记，**一道题都出不来** |

| 一侧「其他」、另一侧题材明确 | 算**不一致** | 一侧满篇题材术语、另一侧看不出题材，评者照样能靠题材分辨 |

| 两侧都「其他」 | 算一致 | 都没线索 ⇒ 没有泄露 |

| 判不出来（空） | 算**不一致**（fail closed） | 不能默认放过 |



## 实测：脱敏后必须重判



第一版判题材判的是**脱敏前**的文本，而评者看的是**脱敏后**的。

⇒ 现在脱敏之后再判一次，判的才是评者真正看到的那段。



## 教训



6. **年代一致 ≠ 题材一致。** 同代不同题材照样泄露 —— 闸门要按**子题材**分，

   而且要有**独立于年代**的那一道。

7. **自己写的词表要先在真实语料上校准。** 「看起来很题材」的词（江湖/将军/系统）

   往往在过半的书里都出现；不量「出现在几本书里」就信 ⇒ 尺本身在拿噪声做判断。

8. **判据要选「读上下文」的那一档。** 词表是统计口径，模型读正文是语义口径；

   前者快但会错，后者慢但认得出世界观。

9. **判了脱敏前的文本 ≠ 判了题面。** 判据要落在**评者真正看到的东西**上。

# 题材闸门落地：六个实现级缺陷（2026-10-31）



> 上面是**设计**。这一节是**实现**：把七道闸门真跑起来，在真实语料上撞出来的

> 六个缺陷 —— 每一个都会让包作废，而且**没有一个是断言能抓到的**。



## 1. 挂回时用循环变量当字典键 ⇒ 各臂的人类侧文本整体对调



```python

for p in plan:

    for (name, off, text), mtext in zip(p["pool"], human_masked.get(name, [])):

        pool_masked[(name, off)] = mtext

```



`name` 是内层 `for` 的解包目标 ⇒ 每轮被覆盖；**进入下一轮时还留着上一轮的值**

⇒ 每一臂都去别的那本书的脱敏结果里取片段。



**实测症状**：都市臂的人类侧窗口是**古风正文**；题材闸门把两侧判成不同题材

⇒ 都市臂「出题 1/2」、古风臂「出题 0/2」。



**修法**：用**显式的书名**取脱敏结果（`book = entries[0][0]`），循环变量另起名；

条数对不上就整包作废。回归测试直接断言「每题的人类侧必须来自**本臂自己的书**」。



## 2. 粗筛分数大面积相同 ⇒ 候选窗口全挤在书的最前面



527K 字的《回声年代》里，**全局最优的 10 个窗口粗筛距离全都是 0.38**（一个不差）

⇒ 「取前 N 个」= 「取 offset 最小的 N 个」⇒ 候选全来自前 10K 字。

再叠加「配对时按 pool 原顺序取第一个合格的」⇒ 题目永远是那本书的开头几章。



**修法**：① 按 offset 把全书切段，**每段取粗筛最优的一个**；

② 配对前**打散 pool 顺序**（固定种子 ⇒ 可复现）；

③ 采样步长（2000）必须大于「窗口不重复」的间隔（1500）。



## 3. 强题材漏了古风武侠与东方玄幻



「内力/真气/镖局/朝廷」「筑基/渡劫/灵根/御剑」是**类型标志**不是日常词

⇒ 一侧满篇武侠、另一侧市井，评者一眼分得出来 ⇒ 与灵异/年代同级。



## 4. 武侠 ↔ 玄幻要算兼容（泄露的本质是**非对称**）



我们侧仙侠臂的产出其实**偏古风**（檐下灯火、玉牌、刀痕，没有修真术语），

人类侧《道途魔典》满篇「修真界/洞府/旗阵」⇒ 模型判成两个不同的类 ⇒ 一道题都出不来。



但**评者分不出「哪种古风」**。⇒ 关键认识：**泄露的本质是「非对称」**

（一侧比另一侧更扎眼 ⇒ 评者能定位），**不是「题材相同」**；

两侧同样扎眼（哪怕题材不同）并不泄露 ⇒ 武侠 ↔ 玄幻 互为兼容题材。



## 5. 判定批大小 30 → 100（一千个候选能把整包拖死）



现代都市文的 4000 字片段能召出 **1000+ 个**候选，噪声占绝大多数

（「他们/什么/没有/自己/公司/解密」）。30 一批 ⇒ 35 批 × 3~10 分钟 ⇒ 两小时

⇒ 直接撞上后台任务一小时上限。



判定成本 = 候选数 ÷ 批大小 × 单批耗时，而**单批耗时与批大小基本无关**（耗时在网络与推理）。



⚠️ 但**批大了会被 max_tokens 截断**（实测 100 词一批回包被腰斩 ⇒ 触发拆批重试

⇒ 反而每批多花 2 次调用）⇒ **两个一起改**：批大小 100 **且** provider 的

max_tokens 提到 16000。截断本身不会致命（`_judge_resilient` 会拆小批重判），

但它是**纯浪费**。



## 6. 随机种子要固定，每臂用独立随机源



不固定 ⇒ 我们侧窗口每次都变 ⇒ 判定缓存（按文本 sha256）**永远命不中**

⇒ 每次都要重跑全部模型调用。每臂独立随机源 ⇒ 可以**分臂预热**

（一个臂一个臂跑，各写同一份缓存），最后跑一次全量 ⇒ 缓存命中、几分钟出包。



> 题材闸门只要 5 分钟，模型调用要两小时 —— **后者才是这个包能不能出的关键**。



## 教训（补）



10. **内层循环变量别当外层循环的键。** 解包目标会覆盖它，下一轮还留着上一轮的值。

11. **尺的分数大面积相同时，「取前 N 个」不是「取最好的 N 个」，是「取最靠前的 N 个」。**

    ⇒ 要覆盖就分组取样；还要打散配对顺序。

12. **同一世界观下的子类型可能分不开**（武侠 vs 玄幻）。判据要问「评者能不能定位」，

    不是问「两边标签是否相同」。

13. **模型调用的成本由「候选数 ÷ 批大小」决定，不由候选数单独决定。**

    批大小与 max_tokens 要一起看。

14. **可复现性是缓存命中的前提**，不是「锦上添花」：随机种子不固定 ⇒ 缓存永远空转。

# 第三次作废与两次工具自身的 bug（2026-10-31）



> 上面的六条是**出包逻辑**的问题。这一节是**两把尺自己坏了** ——

> 而且这两把尺坏了很久，**一直「通过」**。



## A. 残片剔除在盲评场景会**漏遮真名**



**症状**：泄露扫描报「判定成专名的词仍留在题面里」——「潇潇」（《回声年代》里

冷潇潇的昵称）。它在人类侧的缓存里明明被判成 `character`，却没被替换。



**根因**：`drop_fragments` 按「独立出现率」剔除碎片

（independent = count(A) − Σ count(更长的含 A 的词)），

而盲评脱敏把**整本书**传进去统计：



- 全书里「潇潇」几乎只作为「冷潇潇」的一部分出现 ⇒ 独立出现率 < 0.15 ⇒ 被当碎片丢掉；

- 可它在我们的 400 字窗口里是**单独出现**的 ⇒ 真名原样留在题面里。



**修法**：盲评链路**不丢碎片**（`keep_all_names=True`）——

「替换后剩下半个名字」这个问题由**长名优先替换**解决（「冷潇潇」先于「潇潇」被替），

不需要靠丢碎片 ⇒ 关掉它没有副作用。主链路（建实体表）行为不变。



**教训**



15. **摘要是按「统计范围」算的，换了范围结论就变。** 同一个函数在全书与片段两种

    口径下给出相反答案 ⇒ 必须显式区分，不能靠默认值。

16. **「更严格」不等于「更安全」**：碎片剔除是为了不遮坏，漏遮真名是**更严重**的事。



## B. 泄露扫描自己的两个 bug ⇒ 口径 1 与口径 4 一直是**假通过**



1. **`parse_items` 把 B 段记成 A 段**：换题时 `items.append((cur_id, "A", buf))` 写死了 `"A"`，

   而此时 buf 里装的是上一题的 **B 段** ⇒ 重组时缺 "B" ⇒ **一题都解析不出来**

   ⇒ 口径 4 每次都打「跳过（题面里没解析出题目）」。

2. **题号用的是全角括号**「（s01）」，而代码只认 ASCII `"("` ⇒ 题号永远提取不到

   ⇒ 同上，一题都解析不出来。



⇒ 两个 bug 合在一起：**逐题题材核对（口径 4）从来没真正跑过**，

而它本该在出包后替我们看一眼「哪几题两侧题材不同」。



3. **口径 1 是跨书搜的**：把每本书的专名拿到**整份题面**里搜 ⇒

   「云深」在《回声年代》里判成 character、在《道途魔典》里判成不是专名，

   只要它出现在题面任何一侧就被报成残留 ⇒ **跨书误报**。

   ⇒ 改成**按书核对**：每题的人类侧片段只用**它那本书**的缓存查。



**教训**



17. **「一直显示通过」的工具，先怀疑它没跑。** 「跳过」≠「通过」——

    输出里出现「跳过」时要当成**未覆盖**来对待。

18. **按书核对才准确**：同一个词在 A 书是专名、在 B 书不是，是常态。

第三个臂用《两界账簿》当人类侧语料（年代题材）。

- **粤语**：「睇眼圈泛红」「梗着脖子强调」「蠢材」—— 整本书是粤语作品。



⇒ 评者（哪怕不懂粤语）也会觉得「这一侧文字怪怪的」⇒ **语言风格比题材更露骨**。

**教训**



19. **人类侧语料的质量也是闸门**：错字、方言、异体字、盗版水印 —— 任何一项

# 第五次作废：闭集和词表**同时**失灵 + 整包问模型是**假阴性**（2026-10-31）



## 症状：八道闸门全过、`blind=true`，逐题肉眼看仍有三道题一侧是另一个题材



第八道闸门落地后出了 17 题包（都市异能 7 + 东方仙侠 10）。

机制上：八道闸门全过、`blind=true`、`blind_reasons=[]`、题面级残留专名 0、

| 题 | 一侧 | 另一侧 | 模型判的题材 |

|---|---|---|---|

## 根因 A：闭集与词表的盲区**高度重合**



- 模型判题材的闭集只有 9 类，「军事谍战」「深山寻人」「情爱纠纷」都不在里面

⇒ 修法：**把词表按整类补齐**（军旅谍战 / 都市野外寻人 / 古风宅斗言情扩充），

选词标准 = 实测命中率 + 「是不是该题材的类型标志」。



⚠️ **泛词不收**：「情报」「任务」「支援」「部队」「潜入」收进来会误伤好题

（实测 s10/s11/s14 各只命中 1 次就被判不对称）⇒ 误伤比漏网更贵。



⚠️ **合并而不是新建**：新建「古风情爱纠纷」会和已有「古风宅斗言情」大面积重叠

⇒ 改成并进已有的类。



⚠️ **定稿要拿真包验算**：定稿后 = 抓到坏题 3/3、**误伤好题 0/14**。



## 根因 B：整包问模型 = **假阴性**（比报错危险得多）



逐题读题面时还发现：《道途魔典》的组织名「聚金阁」**原样出现在 s16 的 B 侧**，

我们侧的原创专名「落雁坳」「慧照峰」也原样留着。

第六道闸门（题面级专名复查）本该抓住它们。



对照实验（同一份文本、同一套代码）：



| 问法 | 输入长度 | 结果 |

|---|---|---|

| 整包一次问（17 题） | **14422 字** | `[]`（模型**放弃**了） |

| 逐题问 | 每题约 800 字 | 报出 6 题残留专名 |



⇒ **长文本让模型沉默而不是报错。**

沉默被当成了「没有」⇒ 闸门判「题面干净」⇒ 整包蒙混过关。

⚠️ 为什么「聚金阁」连**召回**都进不去：整本只出现 6 次

⇒ `pmi_candidates(min_count=20)`（绝对频次召回）够不着；

形状召回（`name_shape_candidates`，只认人名形状）也不认组织名。

⇒ **逐词判定那道闸门压根看不见它** —— 第六道闸门是唯一兜底，它假阴性就直接泄露。



⇒ 修法：`residual_proper_nouns_per_item()` —— **逐题问**，汇总后两侧同时补遮，

最多 `RESIDUAL_ROUNDS`（7）轮，仍有残留则整包作废。



## 教训（补）



29. **闭集与词表会同时失灵**：两者的盲区重合时，同一类题材能同时穿过两道闸门

    ⇒ 补词表要按**整类**补，补完拿真包验算「抓到几个坏题 / 误伤几个好题」。

30. **泛词不进子题材词表**：「情报」「任务」这类顺口就来的词会让好题被误判

    ⇒ 判据是「该词是不是该题材的类型标志」。

31. **新类要并进已有的类**：同一题材两套重叠词表 ⇒ 同一段文本同时命中两类

    ⇒ 断言集合变大、语义含混。

32. **机器闸门全过 ≠ 包是好的**：本轮三道坏题全是肉眼发现的

    ⇒ 出包后**逐题肉眼过一遍**仍是必须的一步。

33. **模型对超长输入会沉默而不是报错**：凡是「问模型一次、拿回答当判据」的设计，

    都要问一句「它读不完时会报错还是沉默」⇒ 沉默 ⇒ 必须加「逐条问/分段问」的兜底。

34. **假阴性比假阳性危险**：报错让整包作废（安全），沉默让坏包过关（不安全）。





# 第六次作废：安全闸门**自己**坏掉 —— 假阳性、假阴性、盲区、轮数（2026-10-31）



## 症状：18 题包卡在两个**不存在的名字**上，真名一个都没漏



用新闸门重出 18 题包（都市异能 8 + 东方仙侠 10）：

八道闸门全过、密度对称（5.36 / 5.55）、`genre_bad=0`、`era_bad=0`，

但 `blind=false`、`emitted=false`：



```

题面里还残留专名（复查没清干净）：＃＃＃、带柳

```



| 报出来的词 | 它是什么 |

|---|---|

| ＃＃＃ | 模型把**已经遮好的占位符**当成专名报回来（提示词里写了「已变成全角井号的位置不用管」—— 提示词挡不住） |

| 带柳 | 《道途魔典》「他带柳入林而入」里的**跨词残渣**（原文说的是「带柳入林」，不是「带柳」这个人） |



⇒ **假阳性也会把整包卡死**：闸门把假阳性当真 ⇒ 反复补遮 ⇒ 三轮补不干净 ⇒ 作废。



## 根因 A：缓存把**否定结论**固化成假阴性



修完假阳性后重新出包，逐题肉眼又抓到三处人类侧没遮干净的名字

（「阿砚」「阿夏」「裴夫人」）。诊断对照：



| 问法 | 结果 |

|---|---|

| 走缓存（旧判定） | s06 干净 ⇒ 放行 |

| 不走缓存，重新问 | s06 报出「麻子」 |



⇒ **模型是非确定性的**：同一段文字问两次，答案可能不同。

「这段是干净的」一旦被缓存，之后每次重建都白捡这个**假阴性**。



⚠️ 缓存键只有正文哈希、**没有判据版本** ⇒ 改了提示词缓存照样命中

⇒ 新提示词永远不会生效。两个坑叠在一起，症状是

「代码明明改了，包还是卡在同一个名字上」。



⇒ 修法：**安全闸门不缓存**（`residual_proper_nouns` 去掉缓存路径）。

代价是每次出包重新问一遍（约 25 分钟），远小于漏遮的代价。



## 根因 B：「称呼型专名」是模型的盲区



「阿砚」「阿夏」「裴夫人」重新问**仍然报 0 个** ——

不是模型偷懒，是提示词口径：只教了「不要列普通词」，

模型于是把「夫人」「阿X」当成泛称。



⇒ 修法：提示词补一节**称呼型专名**判据 ——

亲昵称呼 / 带姓氏的头衔 / 特征外号，

判据是「在文里是不是**特指**某个具体的人或家族」，而不是「像不像常见词」。

⚠️ 提示词示例**必须用虚构人名**（发布版不含真实作品人物名）。



## 根因 C：收敛轮数不够（3 轮）



提示词修好后重跑，第 1 轮就把「阿砚」「阿夏」「裴夫人」「灶|房」全报出来

（改提示词确实生效）。但三轮跑完仍作废：第 1 轮 26 个、第 2 轮 5 个、第 3 轮 3 个。



两个**必然**因素：



1. **模型非确定性** ⇒ 每轮只报出一部分（第 1 轮漏的，第 3 轮才报）

   ⇒ 每一轮都得把**全部题目重新问一遍**；

   只问「文本变了的那些题」等于把漏掉的答案永远锁死。

2. **遮名字会生出残片** ⇒ 遮掉「五塘站」后，「五塘站B口」剩下「B口」，

   它长得像专名，下一轮被报出来 ⇒ 再遮一轮（级联，必然发生）。



⇒ `RESIDUAL_ROUNDS` 3 → **7**（循环遇到第一个干净轮次就停 ⇒ 是**上限**不是固定开销，

实测收敛在第 4~5 轮）。⚠️ 轮数不够时它不报错，只会**一直差一点**。



## 教训（补）



35. **安全闸门不能缓存否定结论**：模型非确定性 ⇒ 一次走运的「干净」会被固化

    ⇒ 之后每次重建都在白捡这个假阴性。代价（重问一遍）远小于漏遮。

36. **判定缓存的键里必须带判据版本**：只按正文哈希做键 ⇒ 改了提示词也不生效。

37. **假阳性也会把包卡死**：「机器闸门卡死」和「机器闸门全过」是同一个缺陷的两面

    ⇒ 闸门要过滤假阳性，但规则必须窄（动词首字规则只在两字时生效，

    否则「藏经阁」这种真地名会被丢掉 ⇒ 漏遮）。

38. **带杂质字符的名字要遮不要丢**：丢了竖线就留在题面上 ⇒ 评者以为这侧被机器处理过

    ⇒ 反而偏向另一侧；遮掉反而干净。

39. **闸门要能看见「形态特殊但确实是专名」的一类**：称呼型专名（阿X／X夫人／外号）

    不是普通词也不是常规人名形状，模型默认口径会漏

    ⇒ 判据要写「是否特指具体的人」。

40. **收敛轮数按最坏情况定**：非确定性 + 遮名级联都是必然的，不是偶发

    ⇒ 轮数不够时不会报错，只会一直差一点 ⇒ 宁可整包作废。



# 教训（补）：强制二选一的量表，**互补的列信息量为零**（2026-10-31）

## 症状：同一个判断被问了三遍

交接夹发出去，主人看记录表一句话点破：

> 「看起来是四个选项，但是其中三个选项，更像人写，有 ai 腔，猜 ai
> 不是一个意思吗，猜了哪个更像人写，另外那个不就是 ai 了么」

## 数学上：那两列的信息量是**零**

记录表要求每列**二选一** ⇒

- 「猜 AI」与「更像人写」**必然取反**；
- 「有 AI 腔」与「更像人写」**必然取反**。

⇒ 两列都是第一列的**函数**，不是新测量；它们唯一的作用是让评者多填 36 次，
并让他以为「多问几遍更保险」。

⚠️ 查代码才发现：判定脚本**从来只用第一列**（`COL_HUMAN`），
另三列只是被读进来，从未参与判定 ⇒ **纯摆设**。

## 修法

1. 记录表只留两列：「更像人写」（判定用）+「主线更清」（**独立维度**）；
2. 判定脚本拿第二列出**交叉表** —— 两列指向不同侧的题 = 诊断信息
   （主线清楚但不像人写 ⇒ 语言层问题；像人写但主线乱 ⇒ 结构层问题）；
3. 备注列留着：评者认出某一侧出自哪本书就写那里 ⇒ 那一题单独剔除；
4. 解析**按表头名**取列，不按位置（删列时正好踩到错位）。

## 教训（补）

41. **强制二选一的量表里，互补的列不产生新信息**：
    设计之前先问「这一列和已有列是不是互补 / 同一个量？」
    ⇒ 要加维度就加**正交**的，或把问题改成**非强制**（「都有 / 都不明显」）。
42. **别把没参与判定的列当成「交叉检验」**：本项目把「猜 AI」当成交叉检验，
    实际它只是第一列的取反 —— 而且代码里它压根没被用。
    ⇒ 「交叉检验」必须**真的算出另一个数**（这里是交叉表），不是换个问法。
43. **解析表格按表头名取列**：列一改，按位置就全错位
    （删列时踩到：旧表按位置读会把「主线更清」读成「有 AI 腔」）。
44. **给别人的表上只放「那个人答得了、且答了不影响别的」的字段**：
    「汇总方视角」的东西（哪边是谁、计数、判定口径）一律不出现在表上。
    本项目的记录表末尾原来有一段「「更像人写」选**我们**那段次数 k = __ / 评者人数 = __ /
    判定 n = 评者人数 × 18」，三个问题任意一个都足以删掉它：
    ① **评者填不了** —— A/B 与「哪边是我们的」是**逐题随机**的（映射在密封文件里），
    评者没有办法从汇总数反推 k，这一栏只会让人瞎填一个数；
    ② **k 不用人填** —— `backend/verify_blind_eval.py` 直接从密封文件算 k 与 n
    （`slot_A` / `slot_B` 决定哪边是「我们」），人手填的那份只会和脚本对不上；
    ③ **它引入了「汇总方视角」的措辞** —— 「选**我们**那段」暗示了
    「有人=我们的产出、有人=不是」。⚠️ 但这不是**新增的实质泄露**：
    题面开头已经说了「一段来自本项目的产出，一段来自人类作品」
    ⇒ 评者本来就知道有一侧是我们产的；这里只是多余的框架提示。
    ⇒ 表上只留：题号 + 两列判断 + 备注；题数写在表头（「一共 N 题」），
    `n` 由汇总方按作答行数算。

45. **尺必须先用阳性对照自证** —— 本轮这把尺坏在**同一个地方**两次：
    ① 动词集合漏了单独的「说」⇒ 产出里真实出现的「才说：“…”」全部漏检
    ⇒ 得出「我们从不写前置归属（0 次）」的**错误结论**，
    整条根因分析都建在坏尺上；
    ② 后置尺把叙述里的「说」也吃了（「…不用说，肯定是他舅舅」）
    ⇒ 假阳性。
    ⇒ 两次都是**阳性对照**先发现的：用**真实文本里出现过的句子**当用例
    （不是编的），一条漏检就说明尺坏了。
    ⇒ 任何新指标落地前，先写一批真实句子的**阳性 / 阴性**对照当测试。

46. **闸门的设计要在真包上验算「抓到几个坏题 / 误伤几个好题」**：
    「某一维不对称 ⇒ 剔除该题」这个设计照抄到新维度上，实测**净效果是负的**
    （剔掉的 10 题里把我们判赢的 2 题也剔了，我们判输的 8 题一个没抓到）
    ⇒ 因为那次失败是**系统性**的（从来不用那种写法），逐题过滤只治零星偏差。
    ⇒ 改成**整包判别力检验**：用**事先登记**的若干条规则在整包上跑，
    能把两侧分开（可判 ≥ 6 对且精确率 ≥ 90%）⇒ 这个包在**这一维**上不盲
    ⇒ 整包作废。**逐题剔除只适合零星偏差，系统性偏差只能整包判。**

47. **前 N 道闸门全绿 ≠ 包能用** —— 本轮八道闸门全过、`blind=true`，
    但盲评真跑判 FAIL（k=2/18，P=0.0007）。漏掉的那一维是**写法**：
    前八道查的是**内容**（专名 / 题材 / 年代 / 脱敏痕迹），
    **一道都不管句法惯例** ⇒ 「出现 `X道：“…”` 的那侧 = 人类侧」这条规则
    在 10 对可判题里精确率 100%。
    ⇒ 闸门清单要**按维度排**（内容 / 痕迹 / 写法…），
    同一维度里再加几条规则是没用的，**缺一整个维度才是真缺口**。
