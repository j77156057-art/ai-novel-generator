# 复盘：一次批次失败 = 一百个真名被判成「不是专名」（2026-10-30）

> 这份文档记的是**实测**过程与数字，不是设想。
> 触发它的不是「模型判错」，是**判定批次失败被静默降级**。

## 发现

18 题盲评包出完后做泄露自查，发现**第 1 题的人类侧原样留着两个人名**，
而我们那一侧是 `＃＃` ⇒ 盲评当场作废（评者看见名字就知道哪边是出版物）。

查判定缓存（`blind_names_human.json`）：

| 现象 | 数值 |
|---|---|
| 缓存里的候选总数 | 1896 |
| 判成**专名**的 | **16** |
| 判成「不是专名」（null）的 | 1880 |
| null 的分布 | **成片出现**（422 / 395 / 231 / 211 / 205 … 连成大段） |

「齐夏」「云瑶」「童姨」「杨间」这些**明显是人名**的词也在 null 段里 ——
一个正常的逐词判定不该这样。

## 根因（探针实测，不是猜的）

```python
verdicts[w] = got.get(w)      # 模型没返回的词 ⇒ 记成 None
```

`_judge_batch` 在**回包解析不出来**时返回 `{}` ⇒ **整批 100 个词**都被记成
「判定为 null」。而 null 的含义是「这个词**不是**专名」。

回包为什么解析不出来？provider 在输出撞上 `max_tokens` 时**只告警、照常返回半截内容**
（`finish_reason=length`）—— 半截的 JSON 数组 `json.loads` 直接失败 ⇒ 整批蒸发。

探针实测：100 词一批**有时**回包完整（`finish_reason=stop`），**有时**被截断 ——
**概率性**发生，所以前 6 题的小包侥幸没中招。

⇒ **一次批次失败 = 100 个真名被记成普通词，还被永久缓存下来。**

## 修法：三层

1. **判定层不许把「没判出来」写成「不是专名」**
   - 新增 `UNJUDGED` 状态，与 `None` 严格分开；
   - 批次失败/截断 ⇒ 拆小批重试（30 → 15 → 7 → 3 → 1）；
   - 拆到 5 个词一批还判不出来 ⇒ 标 `UNJUDGED`，**不进缓存**；
   - 判定缓存带版本号，旧格式整份作废。
2. **脱敏层 fail closed**
   —— 只要有一个候选词处在 `UNJUDGED`，抛 `MaskingIncomplete` ⇒ 整包作废、题面不发。
3. **新增第六道闸门「题面级专名复查」**
   —— 脱敏后把**成段题面**再读一遍，把还是专名的词挑出来补遮；
   挑到的补遮后重查（≤3 轮）；清不干净 ⇒ 整包作废；补遮 >5% ⇒ 整包作废。

配套：判定用**独立 provider 实例**（`thinking_off=True`、不装成 Writer 单例）；
脱敏的判定批次从 100 降到 30。

## 重出这一版的实测数字（干净语料臂 30 段 → 18 题）

| 项 | 数值 |
|---|---|
| 逐词判定候选 | 我们侧 599 个 / 人类侧 1896 个 |
| 判成专名 | 我们侧 11 个 / 人类侧 42 个 |
| **题面复查补遮** | **5 个**（二虎、林檎、红塔山、老四、齐＃＃）—— 这 5 个**逐词判定全漏了** |
| 复查轮次 | 第 1 轮 4 个 → 补遮 → 第 2 轮 1 个 → 补遮 → 第 3 轮 0 个 |
| 补遮占正文 | 0.1%（远低于 5% 的作废线） |
| 脱敏痕迹密度 | 我们 3.77 / 人类 5.61 个井号每百字（比值 1.49，未触发 2.5 的泄露线） |
| 自检结果 | `blind = true`，理由为空 |

**这 5 个补遮就是第六道闸门的价值**：它们全是真人名（不是普通词），
逐词判定在「一堆垃圾候选里挑名字」时把它们判成了普通词 ——
**换成「读正文、报出还是专名的词」就全抓到了**。

## 交付前的三条独立口径

| 口径 | 查什么 | 结果 |
|---|---|---|
| 判定名残留 | 42 + 11 个判成专名的词逐个回查题面 | **0 处** |
| 题面级复查（新 provider、无缓存） | 把交付的 `blind_samples.md` 整份再读一遍 | **0 个** |
| 排他 + 人名形状（**完全不用 LLM**） | 本书高频、别的书里几乎没有、且是人名形状的词 | 47 个命中，**逐个看上下文全是普通词**（时间/空间/厉鬼/关押厉鬼…），**没有一个是专名** |

## 残余风险（写明，不粉饰）

像「厉鬼复苏」「极道万岁」这种**书里的标志性短语**还会留在题面里 ——
它们不是专名，判定链路按设计不会动它们。
⇒ 脱敏挡得住名字，挡不住「这句我读过」。

## 教训

1. **「失败」和「否定」在数据里必须能分开。** 这一版把两者都编码成了 `null`，
   于是「没判出来」变成了「不是专名」—— 一个**失败被存成了事实**。
   ⇒ 任何「判定/检测」的结果集，都要能表达「不知道」。
2. **缓存会固化错误。** 判定结果按词缓存本来是为了省钱；
   一旦把失败写进去，它就变成了**永久的**判决 —— 而且没有任何症状。
   ⇒ 缓存要带版本号；失败的结果不进缓存。
3. **闸门要独立于被闸的那条链路。** 前五道闸门（年代、密度、对称性…）全都没抓到这次泄露 ——
   因为它们量的都是**痕迹的统计特征**，而泄露是**逐词的事实**。
   ⇒ 复查那一遍必须**换一条链路**（逐词判 → 读正文）。
4. **概率性失败比确定性失败危险。** 这次是「有时截断」——
   小包（6 题）侥幸没中招，大包（18 题）中了。
   ⇒ 越是「一次性发出去、错了当场作废」的产物，越不能靠运气。
5. **上下文不是万能药。** 探针里给候选词附上原文语境，`楚天` 反而从 `character`
   变成 `null`；单独判 5 个词比混在 100 个里判更准。
   ⇒ 修法不是「加上下文」，是「**别把失败当成否定**」。
