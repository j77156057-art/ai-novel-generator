# 盲评包脱敏与防泄露

## 什么时候用

- 要出一个「人写 vs 本项目产出」的**盲评包**（题面 + 记录表 + 密封映射）；
- 要改盲评脱敏链路（召回 / 判定 / 占位符 / 自检）；
- 已经出了包，交付前要确认**没有泄露**；
- 看到「题面里出现了专名 / 密度不对称 / 跨代 / 判定脚本拒绝出结论」这类问题。

## 先认清一件事：盲评包不是「两段文字摆出来」

评者只要能**认出哪边是出版物**，整个包作废 —— 结论不是「弱」，是**没有**。
所以闸门是 **fail closed**：任一条不成立 ⇒ 包标成「不是盲评包」，
`verify_blind_eval.py` **拒绝出统计结论**（退出码 2），题面根本不发出去。

## 六道闸门

| 闸门 | 为什么必须有 | 怎么查 |
|---|---|---|
| ① 两侧同等脱敏 | 人类侧若取自知名作品，人物名一出来就等于举牌 | 两侧专名都换成**等长占位符**（`＃＃`），**同一个函数**跑：召回 → 判定 → 残片剔除 → 替换 |
| ② 取样口径对称 | 「段首 400 字」vs「随机 400 字」的引号密度能差 2.3 倍 | 两侧都随机取 |
| ③ 版式归一 | 盗版站文本带段首缩进、章节标题单独一行 | 两侧都过 `normalize_for_blind` |
| ④ 题材/年代一致 | 一古一今，评者不看内容就能分出 | 年代标记词**份额 + 命中数**，**整包级别**算 |
| ⑤ 脱敏痕迹密度对称 | 两侧井号密度差一大截 ⇒ 数井号就认出来了 | 占位符密度（井号/百字）两侧对比 |
| ⑥ 题面级专名复查 | 逐词判定**会漏**，漏了就是真名留在题面里 | 脱敏后把**成段题面**再读一遍，把还是专名的词挑出来补遮 |

## 脱敏链路（两侧必须是同一条）

1. **召回**（`acceptance_lib.recall_proper_nouns`）—— 两套合并：
   整本/整批高频 PMI（抓得住主角）+ 片段级人名形状（抓得住只出现一次的角色）。
   **只保留真的出现在片段里的候选**（判定按词付费）。
2. **判定**（`app.style.entity_judge.judge_proper_nouns`）—— LLM 逐词判「是不是专名」，
   判据是「能否脱离本书语境独立成立」。
3. **残片剔除**（`drop_fragments`）—— 「赵长」这种只是「赵长安」一部分的碎片要丢掉。
4. **替换**（`acceptance_lib.mask_names`）—— **等长**占位符（一个两字名 → `＃＃`），
   **不带编号**（编号个数本身就是「这一侧有多少个专名」的线索）。

⚠️ 占位符**必须等长**：不等长会把句长指标推高（实测 `【人名3】` 让脱敏文本涨 23%）。

## 判定有**三**态，不是两态

| 状态 | 含义 | 处置 |
|---|---|---|
| 类别（`character`/`place`/…） | 判出来是专名 | 遮 |
| `None` | 判出来**不是**专名 | 不遮（遮了会毁掉正常词汇） |
| `UNJUDGED` | **没判出来**（批次失败/输出被截断/模型漏了这个词） | **当普通词处理 = 把真名留在题面里** ⇒ 绝不能默默放过 |

⇒ 脱敏链路里只要有词处在 `UNJUDGED`，就抛 `MaskingIncomplete`，
**整包作废、题面不发**（fail closed）。

## 批次失败是概率性的，必须能救回来

逐词判定的回包是「每个词一个 JSON 对象」，**批次越大回包越长，越容易被
`max_tokens` 拦腰截断**；截断 ⇒ JSON 解析失败 ⇒ **整批判定消失**。

- 批次失败/截断 ⇒ **拆小批重试**（30 → 15 → 7 → 3 → 1）；拆到 5 个词一批还不行才标 `UNJUDGED`；
- 盲评脱敏的判定批次用 **30**（`acceptance_lib.JUDGE_BATCH_SIZE`），通用链路仍用 100；
- 判定用**独立 provider 实例**：`thinking_off=True`、**不装成 Writer 单例**
  （思考块要从同一份 token 预算里扣，关掉它回包短得多）；
- `UNJUDGED` **不进缓存**（下次还会重判）；
- 判定缓存**带版本号**（`CACHE_VERSION`），旧格式/版本对不上 ⇒ **整份作废**
  （旧缓存正是「漏过名」的那份，继续用它等于继续用错的判定）。

## 第六道闸门：题面级复查

`acceptance_lib.residual_proper_nouns(text, provider)` —— 把**成段正文**交给模型，
问「哪些词还是专名」，输出只是「名字列表」。

- 与逐词判定**输入不同、提示词不同、缓存不同** ⇒ 一遍漏了另一遍能抓住；
- 挑到的就**补遮**（等长占位符，长度守恒）再查，最多 `RESIDUAL_ROUNDS`（3）轮；
- 补不干净 ⇒ 整包作废、题面不发；
- 补遮占正文 > `RESIDUAL_MAX_RATIO`（5%）⇒ 多半是模型把普通词当专名 ⇒ 整包作废。

## 交付前自检（三条**独立**口径）

```bash
python skills/blind-packet-deanonymization/scripts/leak_scan.py \
    --packet <盲评包目录> --corpus <人类侧语料目录>
```

1. **判定名残留**：判成专名的词逐个回查题面 ⇒ 必须 **0 处**（退出码 1 = 包不能发）；
2. **排他 + 人名形状**（完全不用 LLM）：本书高频、别的书里几乎没有、且过 `_valid_name`
   ⇒ 回查题面。**命中不等于泄露**（普通词也会命中），要逐个看上下文；
3. **题面级复查**（新 provider、无缓存）：把整份题面再读一遍。

## 出包之后：判定脚本

- 判定数 `n = 评者人数 × 题数`，**n ≥ 18 才有统计力量**；
  多请人（3 人 × 6 题）判断真正独立；多出题（1~2 人 × 18 题）同一个人的判断**不相关**，
  符号检验会把 p 值算得**偏乐观** ⇒ 结论只能说「倾向」；
- 题数 > 6 时取样要**在整条长跑上均匀铺开**（首尾必留）——否则十几道题落在同一段区间，
  样本量是假的；
- 记录表上的「判定 n = 评者人数 × ?」必须跟着**实际题数**走；
- `blind=false` ⇒ 判定脚本拒绝出统计结论（退出码 2）；
- 自证方式：按密封文件里的映射填一份模拟表（「永远选我们」⇒ PASS，「永远选人类」⇒ FAIL），
  **跑完删掉模拟表**。

## 失败边界（这套方法挡不住什么）

- **挡得住名字，挡不住「这段我读过」** —— 脱敏只处理专名；
  书里的标志性短语（成语化的设定、专有的门派/体系称呼）还会留在题面里。
  这一条要写进交付说明，不粉饰。
- **跨代语料换题材也救不了** —— ④ 是硬闸门，跨代一律作废。
- **人类侧的名天然比 AI 产出密** —— 出版小说的人物名密度本来就高，
  ⑤ 是用来暴露这个不对称，不是用来掩盖它；密度差太多就换语料，别调阈值。
- **闸门量的是统计特征，泄密是逐词事实** —— 前五道闸门全绿也可能漏名字
  （实测就是）。所以 ⑥ 必须**换一条链路**复查，不能复用同一份判定。
