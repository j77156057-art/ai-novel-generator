# 自造示例语料

这里放的是**本项目自己写的**示例语料，不是任何出版作品，也不是网文。

- `示例语料-断铃.txt`：10 章 / 10,443 字 / 约 1.1 万字节，UTF-8、LF、每行一个段落。
- 内容：一个人写的短篇（雪、断铃、两个赶路人）。人物、地名、情节全部虚构。

## 为什么把它放进仓库

README「样例」那一节要展示的是**同一套流水线**的输入与输出：左边这份语料是输入，
右边那段正文是系统拿它当参考跑出来的。语料不公开，读者就没法自己复现。

放进仓库的这份是**自写的**，没有版权问题，所以可以公开。

## 怎么跑

```bash
cd backend
python load_corpus.py --only ../data/demo/示例语料-断铃.txt
```

然后在界面上：建项目 → 选这份语料作参考 → 文风蒸馏 → 生成。

也可以直接看 README「样例」那一节里引用的那一段正文 —— 它就是用这份语料跑出来的。

## 它不适合干什么

1 万字的体量只够**跑通全流程**，拟合出来的文体档案分布带很窄（桶里样本太少）。
要拿到稳的风格迁移，参考语料要 5 万字以上；单本太薄，桶的统计量就不稳。

真要出活，投放自己的语料：见 `data/seed/README-投放真实语料.md`。
